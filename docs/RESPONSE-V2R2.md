## 严重

**S1. "哪个算式对？"有两个对的算式** → 改了。
- 错的选项一律是不成立的算式，正确的永远只有一个：
  - 换一个运算、结果不变（b ≥ 1，所以 `5 − 3 = 8`、`3 + 1 = 2` 都不成立）；
  - 结果差 1。
- 原则和 Z4 一样。
- 验收：`add10`、`sub10` 各 500 题，恰好一个真算式，而且就是答案。

## 中等

- **M1 闪现题和"老朋友来了！"同时开始** →
  - 卡片先盖着。等主持人说完话（`Voice.afterSay`），点才闪 1.5 秒，盖上以后才问"刚才有几个点？"。
  - 第二级提示再闪一次（1.2 秒），不揭晓、不算帮助。
  - 验收用真实时长：一开始盖着；闪的那一刻没有语音在说；问题在闪之后约 1.7 秒；第二级提示又闪了一次。
- **M2 一天内连降两次；过关题不到期也降** →
  - 一张卡一天最多降一次（`m.dn`）。
  - 过关题和漏答补问，在这张卡不到期的日子答错，不动箱，由方案 §12 的"两局都没答对 → 第 1 箱、记一条"决定。到期的卡照常降。
  - 验收：第 4 箱到期的卡答错、补问又错 → 第 2 箱（只降一次）；第 5 箱、20 天后到期的卡作为过关题答错、补问又错 → 不动。
- **M3 Z1 和 Z2 大部分等级是同一道题** → Z1 重做了，每一级都用"="：
  - L1 左边有几块（教 0，保留）；
  - L2 "哪张让两边一样多？"，选项是点卡（没有数字）；
  - L3 "两边一样多吗？"，两边都是点，选 = 或 ≠；
  - L4 同样的判断，两边是数字；
  - L5 天平式 `a + b = ▢ + c`，"方框里是几？"。
  - 揭晓时，中间的"?"变成绿色的 = 或棕色的 ≠，说"一样多！" / "不一样多！"；
  - 答错就事论事说"两边不一样多" / "两边一样多"；
  - 新句子都录了音，≤ 8 字。
  - 验收：Z1 五级 × 4 个种子 × 横竖屏，真实鼠标点答案都能交卷，目标 ≥ 88 px，L3 / L4 两种答案都出现。
