# 用户体验评审（点点岛 · 再玩一圈 New Game Plus · 第 1 轮，Fable 5.1 · high）

你是独立评审。对象是 `index.html`（点点岛）：给 4 岁中文孩子的 iPad 数学 PWA。委托方（家长）2026-10-17：孩子玩到第三个世界，很多题跟不上（不懂加号减号），需要回前面的岛巩固；但插了旗的岛没有动力再玩。为此做了"再玩一圈"，**已先上线**（提交 701afea），这是上线后的评审。

**做了什么**（`docs/DESIGN.md` §14）：插了旗的岛进入第 2 圈：每个小游戏一排新的银色星星（第 3 圈金色、以后彩虹），按原来的星星规则拿（钥匙局、月测、教一教不算）；4 个游戏都集满 → 第 2 圈得皇冠 + 一张英雄卡，第 3 圈得火箭（起飞动画）+ 一张英雄卡，第 4 圈起火箭上 ×2、×3……；插了旗、下一圈没完成的岛有闪光提示；岛面板显示这一圈每个游戏的星和下一个奖励；家长面板显示每个岛第几圈。什么都不锁，往前开新岛的规则不变。奖励图案是代码画的 SVG。录音服务暂不可用，庆祝语复用已有录音（太棒啦！/ 你真厉害！/ 好样的！）。存档：`Store.s.laps`，旧的已插旗岛从第 2 圈 0 星开始，原有的星不变。代码在懒加载的 `assets/js/v2games.js`，`index.html` 里只有几处钩子。

## 请重点检查

1. 对 4 岁孩子：是否真的有动力回去玩；奖励清楚吗（皇冠、火箭、×N）；岛面板和闪光提示看得懂吗；会不会让孩子一直刷简单的岛而不往前走（委托方的目的就是让他巩固，可以接受，但请评估）。
2. 正确性：每一圈的星只按规则拿；不影响原有的星、✓、旗、开新岛、复习、英雄卡顺序；钥匙局 / 月测 / 教一教不计；四个世界和运算岛都能用；存档迁移和 `Store.load` 清洗；卡全部发完后；重复领奖、刷新后重复播放之类的问题。
3. 画面：地图上皇冠 / 火箭 / ×N 和闪光的位置（三种尺寸 1180×820、820×1180、1024×768；四片地图），不挡岛、旗、路和别的岛；岛面板和星托盘。
4. 回归：星星规则、5 个选项、讲解设置、教一教、英雄卡、首屏预算（`tests/test_boot.py`，445 KB / 450 KB）、离线。

## 方法

用 `tests/harness.py` 和 Playwright 自己操作、截图（钩子 `window.__go`、`window.__q`、`window.__state()`、`gesture()`；可直接改 `Store.s` 造场景）。已有测试可以跑，但要自己验证（`test_offline` 的"complete release"一步在这台机器上是已知的环境超时）。截图和数据放 `tests/logs/`，不要改 app 的代码。**非交互模式**：所有命令前台运行（长的分段或加 timeout），结束前一定写好报告。

## 输出

写 `REVIEW-NG1.md`（中文）：1. 总体结论 2. 问题（按严重程度，证据和建议）3. 抽查了什么 4. 单独一行 `SCORE: n/10` 5. 单独一行 `VERDICT: APPROVE`（9 分及以上）或 `VERDICT: REJECT`
