# 点点岛 · 用户体验抽查评审 NG1（再玩一圈 New Game Plus · 第 1 轮）

评审对象：`review/NG1/index.html`（md5 `9bae67d3d0`，与仓库根目录和提交 701afea 逐字节相同）、`assets/js/v2games.js`（md5 `17010ab635`，`Laps` 在第 975–1068 行）、`w3games.js`、`w4games.js`、`sw.js`（都与仓库根目录相同）。
方法：Playwright（Chromium）+ `tests/harness.py`，四个新探针（`tests/logs/ng1/probes/ng1_rules.py` 规则、`ng1_shots.py` 画面、`ng1_real.py` 真实速度、`ng1_edge.py` 边界），直接改 `Store.s` 造场景（27 个岛全插旗、各圈状态），用 `__go` / `gesture()` 真的答题、回家。证据在 `review/NG1/tests/logs/ng1/`：运行记录 `run_rules.log`、`run_shots.log`、`run_real.log`、`run_edge.log`，位置数据 `shots_boxes.json`，截图 `shots/` 42 张，回归套件 `reg_*.txt`。没有改动 app 的任何代码。所有命令都在前台跑完了；没有做完的实验见第 3 节末尾。

## 1. 总体结论

**规则层面做对了，回归全绿；给孩子的"动力"和"奖励是什么"这两件事还差一口气。**

做对的：插了旗的 27 个岛（四片海 + 汽车人算术岛）都进第 2 圈、0 星；答对一题圈星 +1 同时原来的星也 +1，答错两边都不加；钥匙局 / 月测 / 教一教不计（守卫直接调用 + 一局真实的教一教都验证了）；20 颗圈星 → `due`，之后再答对不多算；回到地图：皇冠（got 1，进第 3 圈）+ 一张英雄卡 + "太棒啦！"，第 3 圈火箭起飞 + 卡 + "你真厉害！"，第 4、5 圈 ×2、×3 不发卡 + "好样的！"；卡发完（38 张）后圈照样完成、不报错；`Store.load` 把 n/got/due/g 都清洗了（越界夹住、非法游戏和岛丢掉）；庆祝一开始就存档，中途刷新不会第二次发皇冠、也不丢卡；原来的星、✓、旗、开岛、推荐（手指 / 光圈）一样没动。三种尺寸 × 四片地图的皇冠 / 火箭 / ×N / 闪光都不出屏、不压别的岛的岛身和旗；岛面板的下一个奖励和"第 N 圈"都在面板里；托盘银 / 金 / 彩虹三种颜色都对。回归：boot 12、v2 19、stars 347、opt3 667/668（1 条是本机脚本抓取错误）、explain 1323、w4 812、offline **20/20**（这次"complete release"在本机通过了）；首屏 445.2 KB / 450 KB。

差一口气的：对一个 4 岁、不识字的孩子，这个功能现在只有三个信号——旗边 20 px 的闪光（每个插旗岛永远都有，不是"有事要做"的区别信号）、面板里灰色的皇冠小图 + 他看不懂的"第二圈"三个字、托盘里颜色变了的星。没有一句话告诉他"再玩一圈有皇冠"（录音不可用是客观原因，但现有录音里连"再玩一次吧！"这种话都没有用上）；地图上的手指和光圈照样指向最前面没插旗的岛（E4：第一片海全插旗时指传送门，星空指复仇者空间站）。更要紧的是节奏：原来一个游戏集满 5 颗星有"集满啦！"+ 托盘发光 + 这一局结束 + 新游戏开了；圈里一个游戏集满 5 颗圈星**什么都不发生**（E2：托盘从 4 颗起，每颗新星都落在第 5 格、一局接着往下打，不说话），要连续 4 个游戏共 20 次"第一次就答对"才有皇冠——对委托方要"回去巩固"的孩子（正好是会答错的孩子）这段路很长、中间没有一点回报。所以我判断：功能可以放着用（没有坏处、什么都不锁），但"让孩子有动力回去"这个目标还没达到；见问题 1，改法都很小。

另有两处画面问题（1024×768 时两个葫芦娃岛的旗子和皇冠藏在宝箱下面；面板的圈星被地图透出来的大星星干扰）和几条旧存档 / 时序的小问题。

## 2. 问题（按严重程度）

### 问题 1（中）孩子拿不到中间回报，也没人告诉他回去能得什么

**现象**
- 圈里一个游戏的第 5 颗圈星：`Laps.tray` 把托盘底数压成 `min(4, n)`，`Session.reward` 的 `fullTray`（"集满啦！"、托盘发光、结束这一局）只看 `W2.gameDone`，插旗岛的游戏早就 done，所以永远不触发。孩子看到的是：4 颗星预先亮着，答对一题一颗星飞到第 5 格，再答对一题又飞到第 5 格，一局 5 题打完回地图，什么也没发生（`run_edge.log` E2：`tray start {base 4, on 4}` → `{on 5, full False}` → `{on 5, full False}`，说的只是下一题的题干）。
- 一圈 = 4 个游戏各 5 颗，每颗要"第一次就答对、没用第二个提示"，对需要巩固的孩子一圈可能要十几局、好几天，期间地图上只有一样东西在变：面板里一排灰白的小星星。
- 奖励本身没有名字：皇冠出现时说的是"太棒啦！"、火箭是"你真厉害！"、×2 是"好样的！"（`run_real.log` T3）——和平时答对一题的夸奖是同一批话，孩子分不出这是"更大的事"。英雄卡倒是明确的（"新朋友来啦！"+ 翻卡）。
- 回去的邀请只有闪光：每个插旗岛旗边一颗 20 px 的四角星一直在转（`shots/map_set1_1180x820.png`），6 个岛 6 颗一起闪（E5），没有区别、没有声音；地图的手指 / 光圈仍指向最前面（E4）。"第二圈"是字，孩子不识字。

**建议**（都在 `v2games.js` 的 `Laps` 里，不动首屏）
1. 一个游戏的圈星到 5 颗时给一个"集满"时刻：复用 `Session.fullTray`（已有的"集满啦！"录音、托盘发光、彩带），然后像原来一样结束这一局回地图——既有回报，又让一局短一点；回地图时面板那一格的圈星排可以亮一下。
2. 皇冠 / 火箭出现时至少用一句有区别的已录话，或者等"得到皇冠啦！/ 火箭起飞啦！"录好再上；在录好以前可以把 `Sfx.fanfare` 换成更长的号角 + 让皇冠飞到孩子刚玩的岛的角色头上（现在已经画在头上了，很可爱，可以利用）。
3. 邀请要有一次性的、有声音的时刻：第一次进入第 2 圈的那次回地图（`Laps.st` 第一次创建时）说一句现有录音"再玩一次吧！"（`bluey2.hi`）或"再玩一圈！"录好后用它，并让那个岛的闪光大一点、只在"这一圈还没动过"的岛上闪；可以考虑当孩子在前面的岛连续答错（委托方的场景）时，手指改指最近插旗、圈星最少的岛一次。
4. 把托盘里"已经 5 颗"的游戏做成明显状态（例如 5 颗全亮并微微发光），而不是 4 + 1 反复落。

### 问题 2（中→轻）1024×768 时，葫芦娃·云岛 / 葫芦娃·星球的旗子和皇冠藏在宝箱下面

**现象**：云上和星空两片地图的右上角那个岛（`huluwa3`、`huluwa4`）在 1024×768 时旗布有 42% 已经压在英雄卡宝箱（`#gemchest`，z 12）下面，这是 PT1 加宝箱时就有的；现在皇冠 / 火箭 / ×N 画在旗杆左上，`.lapb` **100%** 在宝箱下面，这两个岛的奖励在地图上完全看不见（`run_edge.log` E3；`run_shots.log` map_set3/4_1024x768 FAIL；截图 `shots/edge_chest_set3_1024x768.png`、`map_set3_1024x768.png`）。1180×820 时云上的 huluwa3 皇冠也有 40% 在宝箱下。820×1180 都没事。

**建议**：`MAPPOS3/4` 把右上角那个岛往下挪一点，或者宝箱在 1024 宽时缩到 88 px / 挪到左上（和 `#gear` 对称），或者 `.lapb` 对右上角的岛改画到旗杆右边。顺带能修好旗子本身被盖的旧问题。

### 问题 3（轻）岛面板里，地图透出来的大星星混在圈星排里

**现象**：面板是半透明盖在地图上的，四排圈星正好落在后面岛屿"十颗变一颗"的大星星那一行高度上：`shots/panel_peppa_1180x820.png` 第 1 排看起来是"3 银 + 1 灰 + 1 金"，第 4 排是"3 灰 + 2 金"——那几颗金的是后面复仇者岛 / 西游记岛的大星。以前这排也是金的，混进去不太显眼；现在第 2 圈的星是白色的，白星旁边冒出金星，更容易把孩子（和家长）看糊涂。1024×768（`panel_paw_1024x768.png`）和竖屏（`panel_bluey_820x1180.png`）也一样。

**建议**：面板打开时把 `#islands` 的 `.bigstars` / 灯托盘再压暗一点（opacity .25），或者给面板底部的四排星垫一条半透明的浅色底。

### 问题 4（轻）旧规则插旗的第一片海岛：游戏自己的星不再显示，"集满啦"来得突然

**现象**：第一片海的旗是"4 个游戏都玩过或 10 颗星"（R5-1）插的，可能有游戏不到 5 颗星、没有 ✓。这种岛现在也进第 2 圈，`Laps.tray` / `Laps.row` 把托盘和面板的那一排都换成圈星：E1（P4 原本 2/5 星、没 ✓）面板第 4 排显示 0 颗（`shots/edge_panel_peppa_P4has2.png`，第 4 个圆没有 ✓ 但下面是 0 颗），托盘从 0 起；再答对 3 题，游戏自己的星到 5，`fullTray` 触发——托盘从 2 颗一下跳成 5 颗、"集满啦！"、这一局结束（`run_edge.log` E1 第三次：`on 5, inGame False`）。逻辑没错（✓ 是按原来的星给的），只是显示上两套星打架。只影响老存档里第一片海这类岛，委托方的孩子多半就是这种存档。

**建议**：`Laps.on(w)` 再加一个条件 `W2.islandDone(w)`（4 个游戏都 ✓ 才算第 1 圈完成），没 ✓ 的岛先按原来的方式把 ✓ 拿齐；或者 `Laps.tray/row` 在 `!W2.gameDone` 时不接管。

### 问题 5（轻）打开 app 时存档里已有 `due` 的圈，能不能当场庆祝取决于懒加载快不快

**现象**：孩子拿到第 20 颗圈星后这一局不会结束（见问题 1），如果家长这时直接收起 iPad，`due` 留在存档里。下次打开：`MapView.enter → after(900)` 在进地图 0.9 s 后跑 `specials`，`Laps` 在 `v2games.js` 里、点"开始"后才加载；`v2games.js` 加载完的那一行（1071）只做 `MapView.update / hello / pending`，不跑 `specials`。本机真实速度（SW 关掉、本地服务器）v2games.js 在 0.1 s 就到了，1.03 s 皇冠出现（`run_real.log` T1）；fast 模式下定时器先于文件到，首次进地图没有庆祝（`run_rules.log` R6 FAIL），要等下一局回地图才补。真机第一次联网安装、或网络慢时会落到后一种。不丢奖励，只是迟一局。

**建议**：`v2games.js` 1071 行那个"文件晚到"的钩子里，若在地图上且有岛 `due`，调一次 `MapView.after(300)`。

### 问题 6（轻）家长面板和卡的经济

- 家长面板的"这一圈的星"用的是游戏代号（`P1 2/5  P2 0/5 …`，`shots/parent_laps_1180x820.png`），家长看不出 P1 是哪个游戏；表格 27 行一屏放不下，但能滚。建议用游戏名（`GAMES[g].name`）。
- 每个岛第 2、3 圈各发一张英雄卡，29 个岛最多 58 张，卡册只有 38 张，加上钥匙局每天一张：卡会比以前早很多发完，之后新岛插旗只得到"卡册满啦！"。可以接受，但请委托方知道；或者圈卡从一个单独的池子发 / 第 3 圈不发卡。

### 观察（不扣分）
- 皇冠画在岛上角色的头顶上（`.lapb` 在旗杆左边，正好是主持人的位置），像给角色戴了皇冠，效果很好（`shots/real_lap2_crown.png`）；×N 的红色小牌有时压在角色脸上一点（汪汪队 ×2，`map_set1_1180x820.png`），不影响辨认。
- 第 2 圈的"银星"实际是白色（grayscale + 提亮），托盘里白星（有描边）和空格（灰圆）分得清（`shots/tray_lap2_1180x820_tray.png`）；第 4 圈起托盘星星 2.4 s 转一圈色相（`tray_lap4_1180x820_tray.png` 抓到的是绿色），算"彩虹"。
- 面板的"第 N 圈"用 `CN[n]`，`CN` 在 `index.html:541` 扩到了 40，第 21 圈显示"第二十一圈"正常（R7）；第 41 圈起会显示"第undefined圈"，一圈要 20 次首答全对，实际到不了，提一句而已。
- 整个圈的庆祝 + 翻卡约 5.8–6.6 s，×N 那次 3.8 s（T3）；时长合适。
- 插旗和圈奖励同一次回地图：先插旗、后皇冠，都发生（E7）。

## 3. 抽查了什么

**规则（`run_rules.log`，46 项，8 条 FAIL 里 7 条是探针自己的选择器 / 语音通道问题，已在 `run_real.log` 里用 `__speechLog` 重验；真正的 1 条是问题 5）**
- 27 个岛全插旗、没有 `laps` 字段的存档：`Laps.on` 对全部 27 个插旗岛为真（含汽车人算术岛 `trans3`），未插旗的复仇者空间站为假；每个岛 `{n 2, got 0, due 0, g {}}`；第一片海 6 面旗边各一个闪光、没有皇冠。
- 五个岛（佩奇 P1、Bluey 新岛 C2、汽车人 Z1、佩奇星球 F1、西游记天宫 S3）：答对 → 圈星 1、游戏星 5→6；答错 → 都不动；再答对 → 圈星 2；托盘 `data-lap=2`、底数 0、亮 1 颗。
- `Laps.star` 对 `key / test / teach` 和未插旗岛不计；一局真实的教一教（`Teach.on` 预设、`G.teach` 为真）答对不加圈星。
- 第 20 颗 → `due 1`；之后再答对不加、没有"集满"时刻、这一局继续；回家后 got 1 / n 3 / g 空、英雄卡 +1（src `lap`）、地图 `['cr','sp']`、游戏星 / 旗 / ✓ 不变；第 3 圈 `['cr','rk','sp']` + 卡；第 4 圈 `rk×2` 不发卡；第 5 圈 `rk×3`；托盘 data-lap 3 / 4 / 4、底数 4。
- 卡发完（gems.n = 38）后完成一圈：皇冠照发、卡数不变、无错误。
- `Store.load`：`{n 1, got -3, due 'x', g {P1 9, P2 -1, ZZ 3, P3 'a'}}` → `{n 2, got 0, due 1, g {P1 5, P2 0}}`；假的岛和字符串丢掉；`n/got 1e9` → 999，`H1 2.6` → 3。
- 面板：第 6 圈四排 `data-n / data-lap` 正确、下一个奖励图标在、"第六圈"；第 21 圈"第二十一圈"。
- 旗 / 开岛 / 游戏星只在玩过的岛变化；零页面错误。

**真实速度（`run_real.log`）**：存档带 `due` 冷启动 1.03 s 出皇冠；皇冠出现后立刻刷新 → got 仍是 1、卡仍是 1 张；一局结束回地图 0.3–0.4 s 皇冠 / 火箭 / ×2 出现，说的话和时长见上。

**画面（`run_shots.log`、`shots_boxes.json`、42 张截图）**：1180×820 / 820×1180 / 1024×768 × 四片地图，各岛分别处于闪光 / 皇冠 / 火箭 / ×2 / ×10 状态：每个徽章的框都在屏内、与自己的旗布 0% 重叠、与别的岛的岛身 / 角色 / 旗 0%（唯一 19% 是竖屏云上汽车人岛的闪光碰到传送门岛的岛身，不碍事），与 HUD 的重叠就是问题 2；岛面板第 2 / 3 / 5 圈 × 三种尺寸；托盘第 2 / 3 / 4 圈 × 两种横屏尺寸；家长面板。

**边界（`run_edge.log`）**：旧规则插旗 + 游戏 2/5 星（问题 4）；游戏已 5/5 圈星的托盘（问题 1）；教一教；推荐指向；6 个闪光 = 6 个无限动画、页面共 26 个动画；插旗 + 圈同一次回地图；1024×768 宝箱遮挡（问题 2）。

**回归（`reg_*.txt`）**：`test_boot` chromium 12/12（首屏 445.2 KB / 450 KB，PT3 时 444.8）；`test_v2` 19/19；`test_stars 3` 347/347；`test_opt3 3` 667/668（1 条 `An unknown error occurred when fetching the script`，和 explain 并行跑时的本机脚本抓取错误，与本次改动无关）；`test_explain` 1323/1323；`test_w4` 812/812（第一次与别的套件并行时 7 条 `ERR_ADDRESS_IN_USE`，是本机端口耗尽，单独重跑全绿，记录留在 `reg_w4_parallel_envnoise.txt`）；`test_offline` 20/20（在仓库根目录跑，"complete release"这次通过）。

**没做的**：没有做 WebKit 引擎的回归（时间关系，PT3 也只跑了 Chromium）；没有真机；复习题（`st.rv`）给本游戏的那颗星是否计入圈星没有单独造场景（代码上走同一个 `Session.reward`，会计入，和原来的星一致）；月测没有跑真实的一局（守卫直接调用验证）。
