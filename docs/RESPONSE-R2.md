## R3 前的自查与新测试发现（本轮新增，均已修正）

新测试（真实指针、旋转、soak、stress、故障注入）与开发方逐张查看 WebKit 真实运行帧，发现并修正了下列问题：

| 来源 | 问题 | 处理 |
|---|---|---|
| stress | 同一只小猪被连点拿走全部雨靴后，“下一步正确操作”仍是“点没有雨靴的人”，而靴架已空——提示手与系统代做会原地循环（P2 活锁） | 靴架空时点人 → 靴架晃动；“下一步”先从多拿的人那里拿回一双 |
| stress / 真实指针 | `numOptions` 允许 0 之后，0 号答案卡在骰子排布下抛错，题目停在无卡片的 `show` 阶段（H3/H4/A1/A3） | 0 = 骰子方框中的虚线空圈；另见下一行的通用兜底 |
| stress | 手势或计时器启动的异步步骤（H3 进洞、H4 定时“拿走”、P1 起跳、X4 吹毫毛）抛错时题目循环看不到，孩子只能按回家 | `gesture()` 监视异步结果；全局 `unhandledrejection`/`error` 兜底 → 本题按 `error` 结束（不给星、不记证据），下一题照常；`test_faults.py` 两引擎验收 |
| 真实指针 | H3 L4 拖进洞后“下一步”仍指向已进洞的那位（提示手会指到洞口） | 改为指向后几位中第一个还在外面的 |
| 真实指针（探测） | X4 翻转里“拨开水帘”重新开放 `act`，此时点悟空会再次施法：分身与答案卡翻倍 | 已提交后不再接受施法；H4 翻转里的宝石同样不再重复计数；**答案一旦提交，所有答案卡失效** |
