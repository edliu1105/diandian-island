# 对 R3 评审的逐条回应（开发方）

R3 原文：`docs/REVIEW-R3.md`（SCORE 6/10，REJECT）。下面逐条说明改了什么、在代码哪里。
代码位置写模块/函数名（行号会漂移）。

**评审方式变更（委托方指示）**：委托方要求停止全部网页测试与 agent 测试，评审改为**只审代码和素材**，由评审根据代码和素材预测孩子的真实体验并打分；9 分为交付标准；评审一共三轮计分（R3 已是第一轮，R4 为第二轮，R5 为最后一轮），R5 之后不论分数都交付。因此本轮快照不附测试日志与截图；下文“验证”一栏如写到测试，是指修改时已写好、已跑过的测试代码（仍在仓库中），本轮不作为证据提交。

## 维度 1 幼儿教学法

| 编号 | 处理 | 位置 |
|---|---|---|
| R3-J01 H3 “总送一个、答一”也能过门 | 两个题型由题型袋交替：`in`（洞里有几个）与 `out`（洞里的娃出到洞口，外面的娃**去巡山**离开画面：“巡山的有几个？”，答案 = 整体 − 洞里）。H3 的单关门新增**分法多样性**：最近 7 个正确证据里洞里部分至少 3 种、外面部分至少 2 种（`game.variety` + `Mastery.gateReport` 的 `varOk`），“总送一个”“总留一个在外面”都过不了门。孩子连续两次用同一种分法时，下一题开头爷爷说“这次换个分法！”。旧版 `selfsplit` 证据按 `in` 计。家长面板在未通过时显示“分法要多样”。 | H3 `kinds/variety/enterCave/reveal/correct/arrange/next`，`Mastery.record/gateReport/kindKey` |
| R3-J02 A4、V1 复述或抄答案 | L1 改为独立题型 `along`（帮手报数、显示累计角标 = 教学，**永不计证据**）；L2 起为 `on`：到达只发升调音，**不说也不显示任何数字**，显示屏为“?”。必需题型 `on` 在世界仍处 L1 时由补测在 L2 出题。V1 教学题的角标淡出后才出卡。 | A4 `kinds/present/lift`，V1 `kinds/present/bring` |
| R3-J03 X4 整体未建立 | 任务卡改为整体 N（数字 + 点阵），全程可见；施法后 N 个分身**一格一个**站开并**一直停留**（不再 700 ms 后自动遮挡），语音“变出N个！”；由**孩子点水帘**才开始躲藏：水雾盖住全场、h 个同时躲进水帘（数不到走动的过程），其余重新站位（空位不泄露答案）。操作：施法 1 + 点水帘 1 + 作答 1 = 3。 | X4 `gen(ptsAll, hide)/present/blow/hideSome/next/gestureHint` |
| R3-J04/G22 V3 只评估填满十 | 新增必需题型 `sum10`：孩子把整条倒进第一个仪表（满十自动停），再把**剩下的**倒进第二个仪表，然后回答“一共几格？”（十和几）。操作 3 步。`split10` 的候选段一律不超过原条长度（`numOptions(G, need, 1, b)`，L1 条长 ≥3）；作答后倒剩余部分的兜底从 4 秒改为 6 秒（该步不计证据，余数的证据在 `sum10`）。 | V3 `kinds/gen/presentSum/pour/labels/correct/next`，`REQUIRED.V3` |
