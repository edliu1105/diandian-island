# 点点岛 · 交付说明

> 给 3 岁半到 4 岁、说中文、还不识字的孩子的 iPad 数学小岛。目标只有一个：**理解**数量与加法，而不是背诵。
> 本文如实记录：教什么、怎么用、测试结论、独立评审的分数轨迹，以及仍未关闭的问题。

## 1. 打开与安装

- 网址：**<https://edliu1105.github.io/diandian-island/>**（HTTPS，GitHub Pages）
- 二维码：`docs/qr.png`；可打印的卡片（含三步安装说明）：`docs/qr-card.png`
- iPad 安装：用相机扫码 → 在 Safari 打开 → 分享 → **添加到主屏幕** → 从主屏幕图标打开（全屏、无地址栏）。
- 离线：第一次联网打开后在地图上停留约 1 分钟（后台下载约 9 MB 素材），之后飞行模式下也能玩；家长面板“离线”一栏会显示“已就绪”。

## 2. 教什么

十二项早期数感按发展顺序分布在六个世界、24 个小游戏里（详细规格见 `docs/DESIGN.md` §1、§4）：

| 世界（等级） | 小游戏 | 认知 | 孩子亲手做的数学 |
|---|---|---|---|
| 小猪佩奇（L1–L3） | P1 溅！ | 瞬识（1–4 知觉、4–6 组块） | 看一眼泥点，床单盖上后选“几个” |
| | P2 穿！ | 一一对应 | 给每只小猪一双雨靴（多给、少给都可能） |
| | P3 收！ ⭐ | 基数 | 一个个收进箱子，箱子关上后回答“一共几个”（L2 起不报数） |
| | P4 插！ ⭐ | Give-N | 听到“插五根”，一根根插到蛋糕上再点火 |
| Bluey（L1–L3） | B1 比！ | 比较 | 找多的 / 少的 / 一样多（三种目标各有无声示范） |
| | B2 买！ | 一一对应 | 一样东西付一个币 |
| | B3 拉！ ⭐ | 守恒 | 亲手把一排拉开；爸爸当面加一块、拿一块或都不动 |
| | B4 补！ | 比较（差几个） | 补饼干直到两边一样多 |
| 葫芦娃（L1–L4） | H1 摘！ | 序数 | 沿藤摸，报“第几个”，摘指定的那个 |
| | H2 站！ | 序数 ≠ 基数 | “第三个上台” vs “三个上台” |
| | H3 分！ | 部分—整体 | 亲手把兄弟分两队，一队进山洞，问洞里几个 |
| | H4 藏！ | 部分—整体（隐藏部分） | 先亲手数宝石（牌子记下总数），隐身的六娃拿走几个，看着剩下的推出拿走了几个 |
| 汪汪队（L1–L4） | A1 派！ | 部分—整体 | 一队狗狗分两个任务，正好用完 |
| | A2 救！ | 合并 / 接着数（L4） | 两辆车救的动物合起来一共几只 |
| | A3 乘！ | 后继 / 前驱 | 亲手让狗狗进 / 出电梯（一两只），楼层尺上走一格或两格 |
| | A4 接！ ⭐ | 接着数 | 篮子里已有几只，接着把小猫吊上去 |
| 西游记（L1–L4） | X1 长！ | 接着数 | 金箍棒从几节变到几节 |
| | X2 翻！ | 接着数（数轴） | 先猜筋斗云落点，再亲手一格一格翻 |
| | X3 装！ | 凑五 / 凑十 | 选刚好装满篮子的那一枝 |
| | X4 变！ | 部分—整体（L3 起 = 十的组成） | 分身躲进水帘洞，从总数和外面剩下的推出躲进去几只 |
| 复仇者（L1–L4） | V1 集结！ | 接着数 | 战机里几位 + 传送门又来几位 |
| | V2 举！ | 十和几 | 一箱十个 + 散的几个 = 十几 |
| | V3 充！ | 凑十 | 先补满第一个仪表，剩下的倒进第二个 |
| | V4 解！ | 符号映射 | 照着密码摆出数量 / 读出数量对应的密码 |

每题：语音只说目标（≤8 个字），无声任务卡（初始 → 动作 → 目标）+ 幽灵手示范；孩子动手后出现“翻转时刻”——数学结构自己显形（分合图、十格、连线、数轴跳弧）。答错不打叉、不扣分、没有失败音：先指出差在哪，再用这一技能专属的方式带着看，然后换一道同类新题。

## 3. 怎么用

- **孩子**：点开始 → 地图上点一座岛 → 岛下四个小游戏徽章，发光的是推荐的那个（证据最少的一关）→ 玩一节（5 轮或约 150 秒）→ 星星飞回岛上的星灯，从已有数量接着报数；满十颗合成一颗大星（= 一个十）。第 3、5、10 次来到同一个世界有小故事（礼物、欢迎队、帽子），留下的装饰会一直在。
- **听不到声音**：地图上方会出现大喇叭，游戏里头像会“呼吸”；点它就在点按当下重说。
- **家长**：长按右下角小齿轮 1.6 秒 → 两道两位数加法（数字键盘输入，答错冷却 30 秒）→ 家长面板：语音诊断（测试发声、选择中文声音、“我听见了”）、每个世界的等级与**难度下限**、通过条件的进度、数字显示开关、全部解锁、清空进度。
- **解锁**：佩奇与 Bluey 默认开放；两者都通过后开放葫芦娃，依次往后。通过 = 四个小游戏各自“最近 7 个独立作答 ≥6 对且最后一个对”、关键题型都答对过、等级 ≥2、两次好的一节、近 12 题正确率 ≥75%。用过提示、重听、系统代做、引导题、示范题都不计掌握；参与星每轮照常给。

## 6. 未关闭项（如实）

1. **品质分停在 6/10（R3），没有拿到 APPROVE。** R3 的主要扣分点（H3/A4/V1/X4/V3 的掌握证据、无语音设备解锁、失声检测、旋转与后台、版本切换、门禁脚本）在 R3 之后都已改代码，但**没有独立评审确认**，也没有在最终版本上重跑完整门禁（按委托方指示停测）。最终版本只做了抽查（见第 4 节）。
2. **视觉统一性**：39 张角色图不可改画；生成的道具/背景与角色画风的统一靠描边、阴影、世界材质与背景让位，**未整体重绘道具**，R2/R3 都把“同一画师”列为扣分项。
3. **真机未验收**：真实中文 TTS、静音开关与媒体会话、离线从主屏幕启动、真机帧率与温度，只能在 iPad 上验证，清单见 `docs/IPAD-CHECKLIST.md`（尚未回填）。
4. **Playwright 在 Windows 上的 WebKit 没有 Web Audio、不能模拟离线导航**：报数 mp3 的实际播放与 WebKit 离线启动只在 Chromium 上自动验证过。
5. **语音对象保留**：为规避 WebKit 回收朗读对象导致 `onend` 丢失，保留最近 24 个朗读对象（有上限，不随时间增长）。
6. **角色互动的上限**：角色图是整张贴纸，互动只能用整图动作（走、转、跳、击掌）加特效，没有逐肢体动画；钢铁侠面罩开合用推进器光效替代。
7. **IP**：六个 IP 的角色形象权利归原权利人，本项目按委托方要求使用其提供的图片，仅供家庭非商业用途；如需下架，见 `docs/DEPLOY.md` 的一条命令。
