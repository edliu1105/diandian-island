# 点点岛 · iPad 真机验收清单

自动化测试（Playwright：Chromium + WebKit）覆盖了代码层能证明的一切，但下面这些只有真 iPad 能验证：静音开关、媒体会话、真实中文语音、切后台/锁屏、离线从主屏幕启动、真实手指。每项做完打 ✓；有问题时在“家长面板 → 语音诊断”截图，连同现象一起记下。

## 0. 准备（约 5 分钟）

- [ ] iPadOS 17 或更新；Safari。
- [ ] 设置 → 辅助功能 → 朗读内容 → 声音 → 中文（中国大陆）：下载 **婷婷（增强）**（没有也能用，但增强版更自然）。
- [ ] 音量调到一半以上。

## 1. 安装

- [ ] 用相机扫 `docs/qr-card.png` 上的二维码 → 在 Safari 打开 `https://edliu1105.github.io/diandian-island/`。
- [ ] 分享 → 添加到主屏幕 → 名称“点点岛”，图标是岛屿。
- [ ] 从主屏幕图标打开：全屏，没有地址栏，没有任何浏览器痕迹。
- [ ] 联网状态下停留在地图上约 1 分钟（后台下载约 9 MB 的离线素材）。
- [ ] 家长面板 → “离线”一栏显示“已就绪：228 个图片与声音已存到本机”（若显示“还没准备好”，再联网停留一会儿）。

## 2. 声音（最重要）

- [ ] 点入口的绿色播放键：**立刻**听到“我们去点点岛玩吧！”。
- [ ] 进入任意一关：开场语音、报数（“一、二、三……”）都清楚，讲解和报数不互相打断、不重叠。
- [ ] 把侧边**静音开关**打开（或控制中心静音）：再玩一题——报数和音效仍然能听到（无声媒体会话生效）。记录讲解语音在静音时是否仍发声：______。
- [ ] 连点头像 20 次：只说最新的那一句，之后一切正常，不会卡住。
- [ ] 家长面板 → 语音诊断：中文声音 ≥1 个；点“测试发声”能听到；点“我听见了”。
- [ ] 如果完全听不到声音：地图上方出现一个大喇叭按钮，点它会在点按当下重说；它出现时脉动四下，之后安静地留着（头像不再同时闪）。
- [ ] 家长面板 → 设置 → 打开“看图模式”：佩奇“插蜡烛”一关直接显示要插几根的点阵；用完记得关掉。

## 3. 切后台 / 锁屏

- [ ] 作答中按 Home 回主屏幕，30 秒后回来：声音恢复；提示没有在后台“偷跑”（回来后不会立刻出现系统代做）。
- [ ] 作答中锁屏再解锁：同上。
- [ ] 快速切走再切回 5 次：无卡死、无重复播报。

## 4. 旋转

- [ ] 作答中把 iPad 横竖来回转 4 次：画面立即按新方向重排，没有东西跑出屏幕、没有滚动条。
- [ ] 拖着一个物体时转动 iPad：物体弹回原位，题目仍可继续。
- [ ] 答对后的动画中转动：下一题在新方向正常出现。

## 5. 离线

- [ ] 打开飞行模式 → 从主屏幕打开点点岛：正常进入。
- [ ] 六个世界各玩一题（未开放的世界先在家长面板“全部解锁”）：没有破图，报数有声音。
- [ ] 关闭飞行模式后照常使用。

## 6. 手指与孩子

- [ ] 所有能点的东西一指就能点中；拖动跟手；松手才触发。
- [ ] 进入一关后放着不动约 20 秒：先有一位伙伴看向孩子；5 秒主持角色探身、再说一遍题目；10 秒主持角色招手（两声轻呼），然后才出现手势示范；15 秒主持角色打哈欠（两个小“z”、轻轻的哈欠声），然后小手才指路。**同一时刻只有一样东西在提示**，任何一碰全部收回。
- [ ] 答对后的庆祝（表扬 + 星星飞进星槽）不超过约 2.5 秒；地图上星星飞进星灯时点一下屏幕直接跳到结果。
- [ ] 随便玩几关（尤其汪汪队“救！”）：数字、光圈、小旗、徽章从不被篱笆、车、角色挡住；站得靠前的角色在前面（莱德不会被身后的狗狗压住）。
- [ ] 小朋友拍打、连点、手掌压屏：不会进入家长功能，不会卡住。
- [ ] 长按右下角小齿轮 1.6 秒 → 家长验证（两道两位数加法，用数字键盘输入）；短按只出现提示条。
- [ ] （建议）设置 → 辅助功能 → 引导式访问：打开后三击侧边键可把孩子“锁”在点点岛里。

## 7. 耐久

- [ ] 连续玩 15 分钟：不发烫、不掉帧、声音不变形。
- [ ] 退出到地图时星星飞进岛上的星灯，从已有数量接着报数。

## 8. 更新

- [ ] 维护者推送新版本后，联网打开一次，关掉，再打开：是新版本（家长无需操作）。
