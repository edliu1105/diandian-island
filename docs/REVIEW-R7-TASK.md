# 用户体验抽查评审（R7，Fable 5.1 · high）

你是独立评审。对象：`index.html`（点点岛，给 3 岁半到 4 岁、不识字的中文孩子的 iPad 数学小游戏 PWA）。R6（第二世界首轮评审，7/10）的问题已修。之后委托方又提了几项改动，这一轮主要看这些改动的**用户体验**，顺带抽查整体有没有退步。设计说明见 `docs/DESIGN.md` §10（第二世界、入口、旗子、第二世界的新画面）和 §3/§4 里“解锁”一条。

这一轮的改动（委托方的要求）：
1. **进度一关一关开（两个世界同一套规则）**：一开始只开第一片海的佩奇岛，岛里只亮第一个小游戏；一个小游戏玩完一节或在它上面拿到 5 颗星，打 ✓、下一个亮起（回地图说“新游戏开啦！”并打开岛面板）；一个岛的小游戏都打了 ✓，插上这个岛的旗子，然后下一个岛的云才散开。旧存档不收回任何进度。
2. **旗子可以收集**：每个岛的旗子不一样（岛的颜色 + 主持角色头像；第二片海是燕尾旗、旗杆顶有金星）。插旗时旗子长出来并数一数“七面旗子啦！”。岛面板里玩过的小游戏打 ✓，一排最后是这个岛的旗子（没拿到是灰色虚线框）。
3. **第二世界的入口是惊喜**：不在角落放按钮。第一片海正中间一开始是一朵带星星的云；六个岛都过关后云飞走、升起魔法门（“惊喜来啦！”）；点门有转场，到紫色的第二片海（“新的海岛开啦！”）；第二片海正中间也有门，点它回第一片海。
4. **致谢的大结局移到第二世界**：灯会岛是第二片海那条路的最后一站，被云盖着；七个岛都玩过后打开、播大结局（有睡衣小英雄），之后可重看。第一世界过关不再播大结局。
5. **第二世界要有新鲜感**：六个老朋友的岛在第二片海换了新图，18 个小游戏换了新背景，要数的东西也是新的（都由 AI 按第一世界画风生成；角色仍是委托方原图）。

**评审方式：从用户体验角度抽查，不求全面，要快（约 20–30 分钟）。评的是孩子和家长最终看到、听到、摸到的东西；代码只在发现问题时用来找原因。截图必须亲眼看。**

重点抽查：
1. 过关感：新存档从头玩几节，看锁、✓、“新游戏开啦！”、插旗、开新岛的顺序是否清楚，孩子能不能看懂下一步去哪；会不会卡住。旗子是否好看、能区分、有收集感。
2. 惊喜入口与大结局：造存档看中间的云 → 魔法门 → 转场 → 第二片海 → 回来；七岛全过 → 灯会岛 → 大结局。是否真有“惊喜”，转场是否顺、会不会让孩子迷路。
3. 第二世界的新画面：抽几关横竖屏看新背景和新物件——是否和第一世界画风一致、是否真的“新”、背景里有没有和要数的东西长得一样的干扰物、有没有生成瑕疵（边缘色块、透明、裁切、模糊）、物件是否清楚好认。
4. 视觉 bug：被挡住、裁切、重叠、错位（地图在 1180×820、820×1180、1024×768 下尤其看岛、旗子、门、灯会岛）。
