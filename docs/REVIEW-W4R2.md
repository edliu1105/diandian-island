## 1. 总体结论

第 1 轮的两个拦路问题都真的修好了：旗子数词表延到四十，第 22–28 面旗说的是"二十二面旗子啦！"……每句都有录音，不再有 `undefined`；O4 数字规律 56,000 道题里每个数、每张选项卡都在 0–10，步长只有 ±1、±2。第 1 轮点名的五处玩法重合（N4、O2、I8、I3 L4、I1 L5）都改成了真正不同的玩法而不是换皮：N4 变成把空格全部填满的构造题、O2 变成在石头格子里一步步踩出和为 N 的路、I8 变成数轴上按线索排除、I3 L4 和 I1 L5 都变成"从一个数接着数"。二选一的 F2 L2–L4、M3 L3+、F8 都加了第三个选项；I6/I1/F5 的等待时间实测比上一轮缩短了一半左右（I6 L5 从出题到能作答 19.5 s → 8.4 s）。28 个游戏的出题器经我自己的验算器重算 56,000 道题没有一道答案错、没有一道有两个对的答案；252 次答错实测都只说一句就事论事的话、换同类型同难度的新题，没有失败音；588 句不同的语音全部 ≤ 8 个汉字且全部有录音；112 张截图（三种尺寸）的点按目标没有一个小于 88 px、出屏或被挡；星星规则在真实时长下成立；开门、地图、锁、旗、星星城堡、派对、家长面板、复习混入全部按设计工作；前三个世界、运算岛、复习系统、首屏预算、离线全部无退步。

这一轮仍然不能通过，原因是一个重做出来的新缺陷：**I8 猜数在 L1–L3 把答案直接亮在屏幕上**。每条线索说出来时，被排除的数就变灰，而最后一条线索也变灰之后，数轴上只剩一张亮着的卡——它就是答案；孩子不用听线索、不用想，点那张唯一亮着的卡就得星。复仇者·空间站的起点是 L3，所以孩子第一次玩 I8 就是这样：这个世界最后一个岛的"推理测验"，前 5 颗星（也就是插旗、开星星城堡所需的全部）不需要任何推理就能拿到。这与"星只给孩子自己答对的题"和"不代做"的精神相悖，修起来很小（最后一条线索不自动变灰，或答完再变灰）。其次 I8 L5 有 17% 的题答案是 0，而且全靠"0 是双数"这条知识才唯一；O2 在 L1–L2（葫芦娃·星球起点 L2）只有两条可走的路，仍然是 50% 蒙对，而且 O2 是 28 个游戏里唯一没有任务卡的。其余是小问题。

## 2. 问题（按严重程度）

### P1 · I8 猜数 L1–L3：问题问出来时，数轴上只剩答案那一张亮着

- **现象**：`present()` 对每条线索调用 `shade()`（`w4games.js` I8，`if (!q.sup) this.shade(...)`），包括最后一条；线索都说完才问"……，是几？"。由于出题器保证三条线索下只剩一个候选，L1–L3 问问题的那一刻恰好只剩一张白色的卡。
- **证据**：`tests/logs/rv2/stars.json` 的 `i8`：L1、L2、L3 各 3 个种子，"亮着的卡"全部恰好是 `[answer]`（9/9），L4 则 11 张全亮。`rv2_level0.py`：新存档里复仇者·星球四关起点都是 L3，第一次玩 I8 时 `level: 3, bright: [8], answer: 8`，截图 `rv2/i8_first_play.png`（0–7、9、10 全灰，只有 8 是白的；9 还打了叉）。拼图 `sheets/1180x820_05.jpg`（I8 L1 只剩 1）、`sheets/820x1180_01.jpg`（L3 只剩 8）、`sheets/1024x768_03.jpg`（L2 只剩 0）。
- **为什么要紧**：这是全世界最后一个岛的推理关；孩子在 L3 拿满 5 颗星、这个岛插旗、星星城堡开门，整个过程不需要听懂一条线索。"变灰"作为支架本身是好的（第二片海 J2 没有），但支架不能把最后一步也做掉。
- **建议**：L1–L3 只把前面几条线索排除的数变灰，最后一条线索不变灰（孩子自己做最后一步排除）；或者线索全部说完后不变灰，答对后再按线索一条条灰下去作为讲解（现在 `reveal()` 已经这样做了）。L4–L5 不变。补一条测试：问出问题时亮着的卡 ≥ 2 张。

### P2 · I8 L5：17% 的题答案是 0，全靠"0 是双数"

- **证据**：`rv2_misc.py`：L5 400 题里 69 题答案是 0，69 题全部含"是双数"线索；例如线索"不是二 / 是双数 / 比三小"→ 0，"不是二 / 是双数 / 比四小"→ 0。答错时说的是"一不是双数"（`wrong.json` I8 L5）。
- **为什么要紧**：对 4 岁孩子，"双数"刚在这一关出现，"0 也是双数"是额外且有争议的一步；0–10 的数轴上 0 的点阵是空的，孩子很难把"成双"和"一个也没有"联系起来。
- **建议**：L5 生成时排除答案为 0 的组合（或"是双数"线索只用于 2–10）。

### P3 · O2 走哪条路：L1–L2 只有两条路（50% 蒙对），而且没有任务卡

- **证据**：`rv2_misc.py` `o2_ways`：L1、L2 的 2×2 格永远只有 2 条路，L3–L4 3 条，L5 6 条；葫芦娃·星球起点是 L2（`rv2_level0.py`：`level: 2, ways: 2`）。`uniq.json` O2 的 `nopt` 为空是因为没有选项卡，但路数就是选项数。代码扫描（`rv2` 里的 `K.task` 统计）：28 个游戏里只有 O2 的 `present()` 没有 `K.task(...)`，截图 `sheets/1180x820_08.jpg`、`1024x768_04.jpg` 里 O2 顶部中间没有任务卡（其它游戏都有"图标 → ?"）。
- **为什么要紧**：第 1 轮 P4 指出 O2 两条路 50% 蒙对，这次改成走石头确实好玩、清楚，但起点 L2 仍是二选一，而且 L1–L2 有累计点阵条，孩子走到最后一块石头之前已经能看出加起来对不对——也就是说靠"看条"而不是靠算。没有任务卡意味着听漏了语音的孩子没有视觉提示（其它游戏答错后重问时任务卡的小手会再点一次）。
- **建议**：L2 起用 3×2 或 2×3（3 条路），L1 保留 2×2；给 O2 加任务卡（石头 → 星球 → ?）。

### P4 · 仍有三处二选一（委托方已接受，记录在案）

### P6 · 小问题

- **O4 L1–L2 与第二片海"接：城市数字路"相近**：L1、L2 的 400 题全部是 ±1 的数列（`rv2_misc.py` `o4_step1`），"0、1、2、3、?"就是接着数；L3–L5（±2、问号在中间 / 开头）是新的。可考虑 L2 起就用 ±2，L1 用"从中间缺一个"。
- **同岛内的轻微重合**：I3 L4（图 + 数卡"又来了 b 只"，从图接着数）与 I1 L5（盖上的罐子写着 a，再落 b 颗，从数接着数）是同一个"从一个数接着数"的范式，分别在 Bluey·星球的第 1、3 关；教学上这正是要练的，但两关的 L4/L5 对孩子看起来像同一道题。
- **F2 的 `=` 干扰卡有时"半真"**：`a ○ a = 0`（例如 `4 ○ 4 = 0`）或 `0 ○ 1 = 1` 时，`=` 放进去前半句是真的（4 = 4、1 = 1）；L2 有 42% 的题三个数里有两个相等（`f2_eq`）。答错时说"四不等于零 / 零不等于一"是对的，只是干扰卡的"错"不够一目了然。
- **几个级别题目种类很少**：I4 L4 只有 8 种不同的题（正方形加一条对角线 + 0/1 个三角形，左右翻转）、N3 L2/L3 各 6 种、I8 L1 5 种、M4 L5 16 种（`uniq.json` 的 `keys`）。I8 L1 和 N3 L2 作为入门级别可以接受，I4 L4 建议再加一两种图。
- **M1 L5 不一定比 L4 难**：L5 把"划掉"换成"飞出陨石坑"的动作图，是换了表示法而不是加难度（L4 的"总数对、剩下不对"干扰图更难）。
- **O3 L5 对 4 岁偏难**（第 1 轮已提，保留原样）：三层缺中间一块且它下面一块也空，要先算 1+3 再用 7 减（`sheets/1180x820_08.jpg` O3 L5）。
- **测试工具**：`rv2_stars.py` 开局读到的星槽数是上一局残留的（`after_wrong` 的第一个 `tray: 1`），是我的读取时机问题不是 app 问题；按游戏星数、本局星数看，9 个游戏的星星规则全部成立（见第 3 节）。
