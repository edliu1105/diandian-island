# 点点岛 v2 第一期 · 用户体验抽查评审（V2R1）

评审：Fable 5.1（high）· 独立评审 · 2026-10-08
对象：`review/V2R1/index.html` + `assets/js/v2games.js`（与主干 `main` 0078a0a 逐字节一致）
方法：`tests/harness.py` + Playwright（Chromium），自己操作、真实指针点按、截图；截图与数据在 `tests/logs/v2r1/`，各次运行日志在 `tests/logs/v2r1_*_run.txt`。没有改 app 的代码。

## 1. 总体结论

方案的骨架基本都搭起来了，而且大部分按 PLAN-v2 的字面做对了：技能卡 / 算式卡的 7 箱间隔、复习星上限 2 颗、第二级提示后不给星、钥匙和 36 颗宝石、复习伤动力自动降档、家长面板的各项、旧存档迁移、运算岛放在云上开头或孩子所在岛之后、Z1–Z4 每题只有一个对的答案、数随等级递进、离线和首屏预算都过。运算岛本身的画面干净、好懂，四种玩法确实是新的。

但有两件事让这一期还不能交给孩子：

1. **复习题直接画在本关的场景之上，场景没有让开。** 在葫芦娃「摘！」(H1) 里，复习的方块和算式卡被藤的透明命中层盖住，**真实点按没有反应**；在汪汪队「乘！」(A3) 里，电梯楼层尺（z 50）压在三张算式卡中间，**加号 / 减号被遮住，三道算式分不清**，点卡片中央也点不中。这两关都在第一片海，孩子第二、三天就会碰到到期卡。84 关 × 5 种题型 × 横竖屏的全扫，横屏 38 个、竖屏 25 个复习画面有题面元素被场景遮住 20% 以上（第二、三片海干净）。
2. **"过关题"在正常游玩里不会出现。** 一个游戏第一次玩只有 4 轮（有示范），至少要两次会话才能集满 5 颗星；而每次会话里本关自己的题答对就把会话 id 记进 `pass`，两次就算"过关"，后面的游戏就不再问。实测 P1 玩两局 → P3、P4 一道过关题都没有。PLAN §12 这一整条（换表征复查、两局不过降箱并记一条给家长）在实际使用中是死的；`test_v2 D-05` 过是因为它直接写 `played` 而不建记忆。

此外有几处与方案偏离、对 4 岁孩子不够清楚的中等问题（试探失败不恢复支架、本关答错不到期也降两箱、运算岛在天空里的次序会漂移、两处点按目标小于 88 px、「搬走了几箱」把搬走的箱子摆在眼前、钥匙局用别的游戏的开场白）。

**结论：REJECT，6/10。** 修掉第 1、2 条和中等问题后，这一期有希望到 8–9。

## 2. 问题（按严重程度）

### 严重

**S1. 复习题压在本关场景上；H1、A3 里复习题点不中、看不清**

- 证据：
  - `cover_H1_give10_L.png`：H1「摘！」里出「给我 N 个」，12 个方块叠在藤上。藤的命中层是一个 1003×277 px、透明、`pointer-events: auto`、z 8 的 div，盖住全部方块。用真实指针点第一个方块：`inB=false, childOps=0`（`cover_notes.txt`）。
  - H1 出「哪个算式对？」：上面两张算式卡同样被盖住，点正确卡片中央 `submitted=false`。
  - `cover_A3_add10_L.png`：A3「乘！」的楼层尺（class `note`，85×461 px，z 50）画在三张算式卡正中间，把 `+`/`−` 完全挡住——三道"1 ? 1 = 3 / 2 / 0"看起来一模一样；点正确卡片中央 `submitted=false`。
  - 全扫（`audit_notes.txt`）：84 关 × `cmp10 / add10 / part10 / on10 / give10`，横屏 38 个画面、竖屏 25 个画面有复习元素被场景盖住 ≥20%，全部在第一片海（P1、P4、B1–B4、H1–H3、A1、A3、V1、V2、V4、X1、X4）。第二、三片海 0 个。
  - 就算点得中，也乱：`rv_add10_L.png`、`rv_add10_P.png`（A4 篮子的黄色标签压在算式卡上）、`rv_on10_L.png`（散点画在直升机上）、`cover_B1_add10_L.png`（Bluey 和盘子留在题面后面）。
- 为什么是严重：孩子按不动、也没有任何反馈，提示梯子不会替他点；他只能回家。回家又会被 `V2D.quit` 记成"在复习题处退出"，三次就触发"复习伤动力"降档——系统会把自己的 bug 诊断成孩子不爱复习。
- 建议：复习题出场时把本关的持久场景（`G.els`、非主持人的角色、各种命中层）隐藏或移到复习层之下，复习层统一 z 最高且独占指针；或者给 `RevGame.present` 一块遮住舞台的素色底板。加一条像 `depth_audit` 那样的门禁：每关 × 每种复习题型 × 横竖屏，用真实指针点正确答案必须能提交，题面元素不被遮。

**S2. 过关题（PLAN §12）在正常游玩里不会被问到**

- 证据（`audit_notes.txt` P/P2）：
  - 新存档，P1 用两局玩到 5 星 → `sub5.pass` 已有 2 个会话 id → `Mem.passed('sub5') = true` → 接着玩 P3、P4，五轮全是本关自己的题，没有一道过关题。
  - P1 一局就 5 星（只有 `noDemo` 才可能）→ P3 问了一次 `sub5`，P4 又不问了（本关答对 + 过关题答对 = 2）。
  - 真实情况里每个游戏第一次来只有 4 轮（有示范，`G.rounds = 4`），不可能一局集满 5 星，所以每个游戏至少两次会话，卡总是先被"自己的题"标成已过关。
- 后果：方案里"本岛每个主线节点一道过关题、两局不过降到第 1 箱并给家长记一条"整条失效；家长面板"换个样子问两次都没对"的信号永远不会亮。
- 建议：`pass` 只记复习题型（`st.rv`）的答对，本关自己的题不计；或单独一个 `passRv`。`test_v2 D-05` 改成从头正常玩 P1 两局再看 P3。

### 中等

**M1. 试探题失败后不恢复支架，而且卡在"到期"里不动**（PLAN §7）

- 证据（`behav_notes.txt` B/B2）：算式卡 `F+3+4` 在点阵级跨两天各对一次 → `supFor` 给出少一级的试探题。答错（`probe-no`）之后 `supFor` 仍然是 `{sup:1, probe:true}`，`sd` 不清；在 B2 里实测：第 2 题试探答错，两题之后漏答队列把它再问一遍，**还是试探题**（`k: ['fact','F+3+4',1]`）。试探题无论对错箱位、到期日都不动，所以这张卡当天、明天都继续到期，一直是试探。
- 方案要求"试探题遇到困难，立刻恢复支架、换一道题来教"。
- 建议：`probe-no` 时清空 `sd`（回到当前支架，重新攒两天）；试探答对时也让这一天的到期按正常答对处理（箱位和支架分开记，但不该互相冻结）。

**M2. 本关自己的题答错、或第二级提示后答对，在不到期的日子也降两箱**

- 证据（`behav_notes.txt` C/C2）：`on10` 在第 5 箱、20 天后才到期；玩 A4 第一题答错 → 第 3 箱、明天到期；只用第二级提示、全答对 → 同样第 3 箱、明天到期。
- 方案 §6 只说"当前游戏自己的节点**到期时**，这一局的题首答对就算复习"，§23"一道题算不算首测，在作答前就定好"。现在任何一局里的一次失误都当成"忘了"，`part10` 对应 6 个游戏（含 X4 L4 这种更难的变式），"会了"会反复闪回"学习中"，到期数也被撑大。
- 建议：本关自己的题只在卡到期当天影响箱位（每天一次），其余时间只记证据。

**M3. 新存档里运算岛在天空里的位置会漂移**

- 证据（`behav_notes.txt` A/M，`map_sky_drifted_order_L.png`）：新存档没有 `v2pos`（`V2Mig.run` 因为 `v2 === 1` 直接返回），启动时按"已开放的原七岛"重新算插入点。孩子打完运算岛、佩奇云岛开了之后重开 app：`ORDER3` 变成 `[peppa3, trans3, …]`；再开两岛就成了 `[peppa3, bluey3, pjmasks3, trans3, …]`。虚线路径跟着改道穿过中间，进度报告写成"运算岛在云上第 4 个"。旧存档迁移写了 `v2pos`，没有这个问题。
- 建议：第一次进天空（或 `defState`）就固定写入 `v2pos`。

**M4. 两处点按目标小于 88 px（铁则）**

- 证据（`behav3_notes.txt` N，iPad 1180×820 与 820×1180 两个方向都量了）：复习题「给我 N 个」的方块 81×81 CSS px；Z3「卸！」要孩子亲手搬的箱子 74×74 CSS px。其它卡片 150–173 px 以上，宝箱 105 px，没问题。
- 建议：方块、箱子放大到 ≥ 88 px（Z3 两排时错开）。

**M5. Z3「搬走了几箱？」把搬走的箱子摆在旁边，"藏起来的部分"是看得见的**

- 证据：`Z3_L3_L.png`、`behav3_notes.txt` J——8 − ? = 4 的题，车上 4 箱，右边空地 2×2 整整齐齐 4 箱，全部可见。孩子数右边的堆就行，用不到"求部分"。
- 建议：搬走的箱子进门 / 进驾驶室，像 Z2 的棕色箱子那样只留一个"?"，揭晓时再滚出来。

**M6. 钥匙局和月测用的是"最后一个开放岛第一关"的开场白，没有"找回老朋友"的框架；月测不是素色**

- 证据（`shots_notes.txt`、`behav3_notes.txt` H）：钥匙局开场横幅是 T1 的「分！」、语音「分拣机开动啦！」，然后直接「哪个大？」；结束说「玩得真开心！」。月测同样「分拣机开动啦！」然后「给我六个！」；背景是 T1 的车间（`monthtest_q1_L.png`）。地图上虽然说了「找回老朋友！」，进了局里孩子听到的是另一个游戏的名字。
- 建议：钥匙局 / 月测跳过游戏的 verb 横幅和 intro，改说「找回老朋友！」/ 月测用素色底板（方案 §25）。

**M7. 局内自适应（PLAN §11）没有做**

- 证据：`Session.round` / `W2.level` 里没有"最近 4 题错 2 题降一档"的逻辑；第二、三片海和运算岛的等级只由星数决定；第一片海的 `Mastery.adapt` 是 4 题里对 ≤1 题才降，也不是 §11 的口径。
- 建议：按 §11 加一条只影响下一题取数范围、不改星规则的局内降档。

## 3. 抽查了什么

**方案落实（代码 + 浏览器实验，`behav*_notes.txt`）**

- 箱位：新卡 → 第 1 箱明天；到期首答对升一箱、每天一次；答错 / 第二级提示后降两箱明天再考（`test_v2 D-02` 复核 + 自己的实验 C）。
- 复习位：0 / 1 / 2 按到期数；3 只在刹车且已打勾；降档后 1；至少留 2 道本关题（D-03 复核；实验 E、K 的实际序列 `[own, review, own, review, own]`）。
- 复习星：一个游戏最多 2 颗记进托盘，多出的进宝石（实验 K：第二局多出的 2 颗变成 2 颗宝石）；升级只按本关星。
- 第二级提示后不给星：含 Z3 卸货的动作阶段（实验 G，0 星）。
- 漏答：答错的复习卡两题后换数再问；当场的替换题不给星（实验 F：P3 5 轮 4 星，cmp10 3 → 1 箱）。
- 过关题：**失效**（S2）。
- 支架：试探不动箱位（对）；失败不恢复（M1）。
- 钥匙：一天一次、到期题最多 5 道、全错也给钥匙（实验 H：2 题全错 → 钥匙 + 1 颗宝石）；离开 8 天回来直接给（H2）；插旗 +1 颗；第 6 颗召唤擎天柱（`gem_hero_optimus_L.png`、`gem_album_6_L.png`）。
- 降档：连续 3 次在复习题处退出 → `v2low`，给家长一条记录（实验 I）。
- 停船还是继续：12 分钟后弹一次，只是提醒（`stopgo_L.png`）。
- 家长面板（`parent_panel_top_L.png`、`parent_panel_mid_L.png`、`parent_panel_text.txt`）：卡状态表、算式卡支架数、保持率（样本不足时只显示）、早期信号、考一考（只往下调，D-08 复核）、生活数学、月测 15 题无星、复制报告、导出 / 恢复（实验 L 往返一致，坏文本被接住）、停船时长、存储探针、红点。
- 迁移：旧存档玩过的游戏进第 1/2 箱、到期分散 1–7 天、星旗不动（D-01 复核）；已在天空、停在 Bluey 云岛的旧存档：运算岛插在 Bluey 云岛之后且锁着，Bluey 云岛打完才开（实验 A2）。新存档的位置漂移见 M3。
- 运算岛位置：新进天空第一个就是运算岛，彩虹城堡也要它（D-10 复核）。

**运算岛 4 个游戏**（`Z1–Z4_L1–L5_L.png`、`_P.png`、`_reveal`、`_wrong`、`Z1_L1_zero_*.png`）

- 生成器：每关每级 300 题答案唯一、在选项里、数在范围内，Z4 恰好一条真算式（D-07 复核）；Z1 L1 里 0 大约 1/8 的题会出现（40 局 240 题 29 次），揭晓说「空的就是零！」。
- 每级画面横竖屏各看一遍：门 / 合体 / 卸货（动作阶段 + 提问）/ 三个数，L4 换框、Z1 L5 只有算式；答错的话：「不是九个」「这个不是一家」「再试一次！」后换新题，没有红叉、没有失败音。

**孩子的体验**

- 10 种复习题型 + 算式卡三级支架，横竖屏各截一遍（`rv_*.png`），卡片 150–599 px；在西游记 X2 里真实出现的复习：「老朋友来了！」→「哪个小？」（`ingame_review_1_L.png`）。
- 复习 × 全部 84 关 × 横竖屏的遮挡全扫 + 8 个最差画面的真实指针点按（S1）。
- 地图：宝箱、齿轮红点、运算岛与门的位置横竖屏都不压岛（`map_*.png`）。

**铁则**：星只给首答对（含复习）；第二级提示后无星；不代做不揭晓；每句 ≤ 8 字（v2 全部语音句都有录音，`__vmiss` 为空；`能量门，两边一样多！` 刚好 8 字）；88 px 见 M4；家长入口仍是长按齿轮。

**回归**（本机 Chromium）：`test_v2` 19/19，`test_boot` 24/24（首屏 ≤ 450 KB），`test_offline` 20/20（新素材和 `v2games.js` 都在预缓存里，断网后作答正常），`gate3_flow` 9/9，`strict2_check` 9/9，`trace_check` 与 `spotcheck` 见 `tests/logs/v2r1_regress_run.txt`。三片海的旗子、金门、灯会 / 彩虹城堡的流程没有退步；运算岛进了 `ORDER3`，城堡需要它。
