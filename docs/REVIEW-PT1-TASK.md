你是独立评审。对象是 `index.html`（点点岛）：给 4 岁中文孩子的 iPad PWA。家长陪孩子学，委托方（家长）2026-10-11 提了这几项，开发方为了让他马上能用，**先上线、后测试**，这一轮是上线后的第一次评审：

2. **答错后的讲解变成家长设置**（家长面板，长按齿轮进入）：关 / 自动（默认，原来的样子）/ 一步一步。一步一步：讲解每一步（每句话、每个圈、每个演示动作）都停下，等家长点一个大的"▶ 下一步"，好让家长一步一步讲给孩子听；没有时间限制，孩子的跳过点按不会跳过，另有给家长的小"跳过"。委托方的原话：讲解 5 秒就播完了，根本没空跟孩子讲。

## 铁则

- 星星只给孩子自己第一次就答对的题；答错的那道没有星，直接下一题；一局错几道都不影响别的题的星；第二级提示之后答对不给星。
- 答错：就事论事一句，然后（按家长设置）讲解，再出新题；没有失败音、没有红叉、不说"错"。
- 每句中文语音不超过 8 个字、都有录音；点按目标不小于 88 px；家长功能只藏在长按齿轮里。

## 请重点检查

1. 每一项是否真的做到了委托方要的样子，对家长和 4 岁孩子是否好用、清楚。
2. **一步一步**：每个世界、复习卡、钥匙局都抽查；每一步是否真的停（推理题至少要分出"他选的为什么不对 / 演示 / 对的为什么对"）；按钮位置不挡选项和角色、三种尺寸都 ≥ 88 px；跳过、切后台、回家、旋转时不卡住；关和自动没有回归。
3. **教一教**：确实降级、确实不记任何进度、确实不丢已有的东西、离开就关、标记清楚；和复习、钥匙局、写字等的交互；会不会被孩子误开（只能从长按齿轮进）。
4. 回归：5 个选项、讲解、星星规则、进度和插旗、复习系统、离线、首屏预算。
5. 画面：横屏 1180×820、竖屏 820×1180、1024×768。

## 方法

用 `tests/harness.py` 和 Playwright 自己操作、截图（测试钩子 `window.__go`、`window.__q`、`gesture()`）。已有测试可以跑，但要自己验证。截图和数据放 `tests/logs/`，不要改 app 的代码。**这是非交互模式**：所有命令都在前台运行（长的分段跑或加 timeout），结束之前一定要写好报告。

## 输出

写 `REVIEW-PT1.md`（中文）：1. 总体结论 2. 问题（按严重程度，每条写证据和建议）3. 抽查了什么 4. 单独一行 `SCORE: n/10` 5. 单独一行 `VERDICT: APPROVE`（9 分及以上）或 `VERDICT: REJECT`
