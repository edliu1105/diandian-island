# 点点岛 · 新世界「积木城」设计（第二片海之后、云上之前）

> 委托方 2026-10-17：孩子很快玩完了第一、二世界，现在在云上，很多题太难。例如看到"5 只小狗，走了 2 只"，他写 5−3：还不清楚 + 和 − 是什么意思，分不清哪个数是"拿走的"、哪个是"还剩的"。要在第二世界和第三世界之间插一个新世界：比云上容易一点、比第二片海难一点，把云上默认已经会的底子补上；内容跟学而思 PreK 课纲走（孩子要上这个课），App 给课堂打配合。
>
> 本文只是设计，不含代码。代码里叫 `w5`（第五个做的世界，`map: 5`），屏幕上叫 **「积木城」**，顺序排在第二片海和云上之间。PLAN-v2 里原来叫"W5"的"20 以内进位加、退位减、整点半点、元"以后改称 **W6**。
>
> 读过的文件：`docs/DESIGN.md` §4、§10、§11、§12、§13、§14，`docs/W4-DESIGN.md`，`docs/PLAN-v2.md`，`docs/OPTIONS-EXPLAIN-SPEC.md`，`docs/DELIVERY.md`，以及 `index.html`（存档校验、地图门环、懒加载）、`raw/js/w2*.js`、`w3*.js`、`w4/*.js`、`v2.js`、`build_w4.py`、`w4_core_patch.py`、`tools/w4_*.py`、`tools/build_all.sh` 的相关部分。

**结论**：
- 空间是短板：位置词（前后、上下、里外、左右，尤其是"关系反过来说"）、迷宫和路线、用三角形拼、数图形。积木城的 28 个游戏里有 21 个以空间为主。

### 3.2 加减的意思：四步，每步在哪里

| 步 | 内容 | 游戏（级别） |
|---|---|---|
| 1 实物和动作 | 听一句故事，自己动手让东西来、走、合起来、被拿走；不出现符号 | P6 小剧场 L1–L4（①） |
| 2 图画 + 故事 | 看"之前""之后"两张照片，判断发生了什么（来了几只 / 走了几只 / 没变） | B6 发生了什么（②） |
| 2′ 整体和部分 | 同一盒包子分成两盒的所有分法，分合图跟着动 | J7（③） |
| 3 明确引入符号 | 每局第一题先演一遍："走了，就写减号！""合起来，就写加号！""又来了，也写加号！"；然后把故事的每一部分放进算式它该在的格子 | A7 对号入座 L1–L3（④） |
| 4 把算式读回故事 | 给一个算式，把里面的每个数放回图里它说的那一群；或照着算式卡演出来 | A7 L4（④）、P6 L5（①的第二圈起） |
| 5 应用题的两种意思 | 合起来 / 又来了都用 +；拿走 / 求另一部分都用 −；最后加"比多少" | V5（⑦）、A7 L2 起混入静态的合并和"求另一部分" |

⑤⑥ 两岛没有加减游戏，但 PLAN-v2 的复习混入（每局 1–3 道复习题）会一直问 ①–④ 进箱的加减算式卡，不会断。

### 3.3 "走了的"和"还剩的"：全世界一套画法

他的 5−3 错误就是把"还剩的"放到了"走了的"的位置。积木城所有涉及减法的地方都用同一套画法和说法，让两者在眼睛里就不一样：

- **走了的 / 被拿走的**：离开时带出门的箭头和动线；原来站的地方留一个**灰色虚线轮廓**（不是红色，不打叉）。讲解时说"走了两只"。
- **还剩的**：原地不动，实线，整群套一个实线框。讲解时说"还剩三只"。
- **又来了的**：从门进来，身上一闪小星光。**合起来的**：两群之间出现一个大括号。
- 讲解时**两句都说**："走了两只，还剩三只"，不只说一个。
- 算式出现以后（④起），讲解时每个数都从它那一群飞进算式格子：一开始的一群 → 第一个格，走了的 → 减号后面，还剩的 → 等号后面。

P6、B6、A7、V5 和它们的讲解都按这一条画。

### 3.4 第一圈基本只玩起点那一级

第二世界起的规则：一个游戏的难度 = 岛的起点 + 游戏的 `boost` + 这个游戏每攒 5 颗星升一级（`W2.level`）。拿满 5 颗星就打 ✓、开下一个，所以**第一圈每个游戏基本只玩起点那一级**（答错多了局内会降一级），更高的级别在"再玩一圈"（§14 的圈数）里才遇到。所以：

- 起点决定第一圈看到什么：①②③ 是 L1，④⑤⑥ 是 L2，⑦ 是 L3。各游戏的 L1–L5 照样每级难一步，供降级、教一教和圈数用。
- 推理测验不再加一级（W2、W3 都加一级，W4 没加）：这个世界的推理测验本身就是他的短板，`boost: 0`。
- A7（对号入座）`boost: -1`：④的起点是 2，但符号要从 L1（拖"一群一群"的图片）开始教。V6（切成一样的）`boost: -1`：从长方形开始。

## 4. 共通约定（实现者照这个写；细节自定，但不得违反铁则）

**代码**：每个岛一个文件 `raw/js/w5/<p|b|j|a|h|x|v>.js`，整个文件包在一个 `(() => { ... })()` 里，只往 `W5R` 上挂规则（`W5R.P5 = {...}`），不留顶层名字。注册在 `raw/js/w5/games.js`。共用小件在 `raw/js/w5/u.js`（`W5U`）。参考写法：`raw/js/w4/*.js` 和 `W4U`。

**规则必须有**（同 W4）：`kind0`、`verb`（一个字 + ！）、`intro`（≤ 8 字）、`praise`（不能和答案相反）、`gen(G, o)`（返回 `{k, answer, opts, ...}`，`k` 决定"同一题"）、`present`、`place`、`relayoutQ`、`onGesture`、`next(st, strat)`（测试走对 / 走错）、`reveal`、`feedback`（就事论事一句 ≤ 8 字）、`explain(st, ans)`、`rightEls(st, ans)`、`decor(G)`、`workEls`、`lines()`（这个游戏会说的每一句，供录音和测试）、`audit(q)`（几个选项、对的在哪、是不是只有一个对）。

**选项**：
- 从几个里挑一个的，一律 5 个（或更多：格子、门、岛上的东西），只有一个对，对的位置用袋子发（`W5U.deal`），数用 `W5U.nums`（答案在五个里的大小名次也用袋子）。
- 本来只有 2–3 种答案的，改成**一题两问**（J8、P8 L4、H6 L4、X5 L5、V5 L1 的设计都算在内）。
- 构造题（摆、画、拼、切、填）不改，每个游戏写明乱点能成功的机会。

**答错以后**：说就事论事的那句 → `explain`：
1. 蓝色虚线圈他选的（或他做的那一部分）+ 一句话，说出它为什么不对；
2. 演示（多数复用 `reveal` 的演示，不欢呼、不夸）；
3. 金圈对的 + 一句话说为什么对。

每一个圈、每一句话就是"一步"（`Step`）；只有动画没有话的演示步显式调用 `Step.beat(st)`。家长"讲解：关 / 自动 / 一步一步"三种设置自动生效。整个讲解约 2–5 秒，点一下跳过。

**每句话 ≤ 8 个汉字**（标点不算），两句的问题用 `W3X.say2`。下面写到的话都数过了；带名字、带数字的话由 `lines()` 枚举。

**88 px**：所有点按目标在 1180×820、820×1180、1024×768 下 ≥ 88 CSS px、在屏内、在最上层。逻辑舞台 1024×704 / 704×1024，缩放 ≥ 1，所以逻辑尺寸 ≥ 88 即可。每个游戏写 `geo()` 的横、竖两套。下文写了几个紧的地方（钉板间距、迷宫格子、4×4 糖盒）。

**题面等待**：故事题从开始到能作答不超过约 6 秒（W4R1 的教训）；一组东西一起动，不一个一个慢慢走。

**背景不画要数、要找的东西**（例如 P5 的游戏室里不能有玩具，B6 的水池里不能有小鸭）。

**数的范围**：L1 ≤ 5，L2 ≤ 7，L3 ≤ 9，L4–L5 ≤ 10；几个几个数到 20。

**复习卡**：只问一个加减事实的题设 `q.fact = factOf(op, a, b)`。每个游戏在 `games.js` 里登记一张卡（`GAMECARD`）：数的游戏用已有的卡；空间游戏用包 D 新加的 `pos`（位置）、`shape`（图形）、`op10`（用加还是用减）；这几张卡的复习题型上线前，这些游戏先登记为空（同 W4 的推理题）。

**铁则**（全部照旧）：星只给自己第一次就答对的题；真正的第二级提示之后答对不给星；不说"错"，没有红叉，没有失败音；不代做；家长功能都在齿轮长按后面；没有第三方库。

### ① 佩奇·积木屋（`peppa5`，起点 1）

#### P5「藏！」捉迷藏：谁藏在哪里 · `hide5`
- **课纲**：F13 Field Trip（描述位置）；测评第 3 题（前后，关系反过来说）。
- **intro**：乔治藏玩具！ **praise**：找得真准！ **主持** george，佩奇是捉的人（捂眼睛）。
- **画面**：乔治的积木游戏室，地面空。地标（SVG）：桌子、积木箱（开口朝上，前板挡住里面的下半截）、大积木块、灌木（新道具 `bush`）、小滑梯。藏的人是 5 个玩具（现有道具：恐龙 dino、小熊 teddy、小兔 bunny、小鸭 duck、小鸡 chick、小猫 kitten、乌龟 turtle），每个约 96 单位。
- **前后的画法要真实**：在后面 = 被地标挡住下半截，只露出上半身，脚的位置更高；在前面 = 脚更低，压在地标前面，挡住地标的一部分；在下面 = 桌腿之间的地上；在上面 = 站在桌面上；在里面 = 在积木箱前板和后板之间露出头；在旁边 = 地标边上，不挡也不被挡。藏起来的玩具的**点按区是单独一层透明目标**（z 46），盖住它整个身体（包括被挡住的部分），所以被挡住的玩具照样能点；`depth_audit` 对 P5 的"在后面"写豁免。
- **手指**：点一个玩具（L4 点一个地标）。
- **L1**：一张桌子，5 个玩具分别在上 / 下 / 前 / 后 / 旁边；问"谁在桌子后面？"（问法在上、下、前、后里用袋子轮）。
- **L2**：桌子 + 积木箱两个地标，5 个玩具在 5 种（地标，位置）上；问法加"里面"；至少一个干扰是"同一个位置词、另一个地标"（问桌子后面，箱子后面也有一个）。
- **L3**：以玩具为参照："谁在小熊后面？""谁在小熊上面？"——玩具之间互相挡、互相叠。
- **L4**：反过来找参照物："小鸭藏在什么后面？"（8 字）→ 点 5 个地标之一（桌子、积木箱、大积木、灌木、滑梯）。
- **L5**：两个条件："在桌子下面，""谁也在小熊后面？"——只有一个玩具两条都满足，每个干扰只满足一条。
- **作答**：5 个玩具（L4 是 5 个地标），对的位置用袋子发；问的位置词用袋子均衡。
- **答错讲解**：
  1. 蓝圈他点的玩具："它在桌子前面"（按它真实的位置生成，如"它在积木箱里面"）。
  2. 演示："在后面"的题，地标变半透明 1 秒，看到后面的玩具："看，它被桌子挡住了"；"在前面"的题，他点的玩具往前一跳："看，它挡住了桌子"。L4 的题，从被问的玩具画一条虚线到对的地标。
  3. 金圈对的："小熊在桌子后面"。
- **就事论事**：它在桌子前面 / 它在积木箱里面 / 它在小熊上面 / 小鸭不在桌子后面（L4）。
- **场景**：`peppa_blockroom`（积木游戏室，墙是大积木，地面空）。新道具 `bush`。
- **复习卡**：`pos`。

#### P6「演！」小剧场：听故事，演出来 · `act5`（题型 `come` / `go` / `join` / `take`）
- **课纲**：F15 Let's Make Cakes（一共、接着数）、S11 Top It Up（合起来、又来了）、S8 Party at Beach（减少、还剩）、S16 Piggy Bank——实物和动作这一步。
- **intro**：小剧场开演啦！ **praise**：演得真对！ **主持** peppa，猪妈妈在台下看。
- **画面**：花园里的积木小舞台：中间一块台子（虚线框），左边一扇积木门（演员从这里进、从这里出），台下两块小垫子（合起来用），佩奇手边一个小篮子（拿走用），右下一个铃铛按钮"演好了"。演员是小鸭、小鸡、小兔，"拿走"的题是盘子里的饼干。
- **流程**：佩奇用 1–3 句短话讲故事，任务卡同时用图标写出故事（开头几个 → 动作图标 → 几个点），听不见的孩子也能做。孩子动手演，按铃提交。
- **手指**：
  - 又来了 n：点门，每点一下进来一只（或从门里拖出来）；
  - 走了 n：把台上的拖到门口，或点它（它自己走出去）；
  - 合起来：把一块垫子拖到另一块上（或先点一块再点另一块）；
  - 拿走 n：把饼干拖进篮子（点饼干也行，它跳进篮子）；
  - 改主意：点刚进来的那只它会走回去，点篮子里的饼干它会回盘子。
- **判定**：台上的结果和故事一样，而且动作对。又来了：原来的都在，正好进来 n 只；走了：正好走了 n 只原来的，没有新来的；合起来：两群在一块垫子上；拿走：篮子里正好 n 块。
- **L1**：开头 1–3 只已经在台上，动作只有"又来了 / 走了"（袋子），n = 1–2，结果 ≤ 5。例："台上有两只小鸭。""又来了一只！"
- **L2**：加"合起来"和"拿走"；结果 ≤ 6，n = 1–3。
- **L3**：开头也要自己摆："先请三只上台！""走了一只！"——先按数取物，再演变化；≤ 7。
- **L4**：两次变化："台上有四只。""来了两只，""又走了一只。"；≤ 8；两个动作都要做对。
- **L5**（第二圈起才会到）：任务卡上是一张算式卡（4 + 2、5 − 3，数下面带点），只说"照着算式演！"——先摆第一个数，再演变化；≤ 9。这就是"把算式读回故事"。
- **作答**：构造题，没有选项；方向和个数都对才对，乱做几乎做不对。
- **答错讲解**：
  1. 快放他刚才做的动作，他动过的东西套蓝色虚线圈："来了三只哦"（或"这是走了哦"）。
  2. 台子回到开头那一刻，开头的一群套框；佩奇再说一遍那句变化，正好 n 只按 §3.3 的画法进来或走掉，进来时接着数"三……四、五"，走掉时倒着数"五……四、三"。
  3. 金括号套住结果："现在有五只"；减法题说两句"走了两只，""还剩三只"。
- **就事论事**：来了三只哦 / 这是走了哦 / 这是来了哦 / 还没合起来哦 / 多拿了一块 / 开始要三只。
- **场景**：`peppa_stage`（花园里的积木小剧场，台面空）。道具全部现成：duck、chick、bunny、cookie、plate；门、垫子、铃铛是 SVG。
- **复习卡**：`add10`；每题 `q.fact = factOf(+/−, 开头, n)`（L4 两步不记事实）。

#### P7「连！」钉板拉皮筋 · `pegs5`（题型 `copy` / `shift` / `sides` / `par`）
- **课纲**：F4 Little Painter（直线、点连成线、线围成形）、S7 Shape Beauty Contest（按边数认多边形）、F5 City Adventure（平行线，L5）。
- **intro**：钉板拉皮筋！ **praise**：拉得真直！ **主持** daddy_pig。
- **画面**：猪爸爸的木头钉板，5×5 个钉（L5 是 6×6），钉距 ≥ 104 逻辑单位（5×5 约 520，横竖屏都放得下）。旁边一块小样板，画着要拉的形状。右下"好了"按钮。
- **手指**：点一个钉（它亮起来）→ 再点一个钉，两钉之间拉出一根彩色皮筋（直线）→ 接着点下一个钉继续拉 → 点回第一个钉就围起来了。点一根皮筋它会弹掉。
- **L1**：照着样板在**同一个位置**拉（板上用小星星标出起点）；三角形、正方形、长方形，边长 ≤ 2 格。

- **L3**：不给样板："拉一个三条边的！"（边数 3 / 4 / 5 用袋子）——随便多大、在哪里都行，只要围起来、不自己交叉、没有三个钉在一条直线上连着用。
- **L4**：照着 5–6 条边的样板拉（箭头、带烟囱的房子），有一条跨 1×2 格的斜边，位置自己选。
- **L5**：板上已有一根皮筋（可能是斜的）："再拉一条路！""和它一样方向！"——拉一根和它平行、不在同一条线上、至少 2 格长的皮筋。
- **作答**：构造题；多种对的拉法都算对（L3、L5），在 `evaluate` 里写清。乱点能对的机会可以忽略。
- **答错讲解**：
  1. 他的形套蓝色虚线，不一样的那根皮筋闪："这里不一样哦"；边数题把他的边一条一条点亮数"一、二、三、四"："这是四条边"。
  2. 样板的形金色滑到板上对的位置（L2、L4 滑到最接近他的位置）："照这样拉"；边数题画一个 N 条边的例子一条条数："三条边！"；平行题一列小火车同时在两根皮筋上开："一样方向"。
- **就事论事**：这里不一样哦 / 还没围起来 / 这是四条边 / 方向不一样哦。
- **场景**：`peppa_easel`（积木房子里的手工角，墙上没有画任何图形）。没有新道具，钉板、皮筋是 SVG。
- **复习卡**：`shape`。

#### P8「记！」动物园记位置（推理测验）· `zoo5` —— **基础包的模板游戏**

### ② Bluey·积木院（`bluey5`，起点 1）

#### B5「找！」左手右手 · `lr5`（题型 `back` / `front` / `mix` / `two` / `side`）
- **课纲**：F14 Lucky Ring（左右；按方向摆放；表达）。
- **intro**：分清左和右！ **praise**：左右分得清！ **主持** bandit。
- **画面**：一排 5 个**积木小人**（SVG：方脑袋、方身子、两只连指手套、两条腿；正面有脸，背面是后脑勺的头发；不是角色图，是通用的小人）。每个小人两只手各拿一样东西：气球（新道具 `balloon`）、花（新道具 `flower`）、冰淇淋、球（现成）、小旗（SVG）。L1–L2 任务卡上有一个背对的小人，右手发光（"右手"的定义），L3 起撤掉。
- **手指**：点一个小人。
- **L1**：5 个都**背对你**（和你朝一个方向，右手就在屏幕右边）："谁右手拿着气球？"。物品 3 种；正好一个小人右手拿气球；至少一个左手拿气球。
- **L2**：5 个都**面对你**。一局第一题先说"它们看着你哦！"（`say2` 的前一句）——它的右手在屏幕左边。
- **L3**：背对、面对混着（各 2–3 个）。
- **L4**：两个条件："右手拿气球，""左手拿花的是谁？"，混着。
- **L5**：小人手里不拿东西，东西放在小人旁边的地上（它自己的左边 / 右边：小猫 `kitten`、小熊 `teddy`、球 `ball`，都是现成道具），混着朝向："谁的左边有小猫？"。
- **作答**：5 个小人；对的位置用袋子；问左 / 问右各一半。
- **答错讲解**：
  1. 蓝圈他点的小人，它举起他当成"右手"的那只手："这是它的左手"（或"它右手拿着花"：手对了、东西不对）。
  2. 面对你的小人：先说"它面对着你"，小人原地转身（正面翻成背面，0.6 秒），两只手在屏幕上换了边："转过来看看"。
  3. 金圈对的小人，它举起右手的气球："它右手拿气球"。
- **就事论事**：这是左手哦 / 它右手拿着花 / 它的左边是球。
- **场景**：`bluey_blockyard`（Bluey 家后院，积木游乐角，地面空）。新道具 `balloon`、`flower`。
- **复习卡**：`pos`。

#### B6「变！」发生了什么 · `what5`（题型 `came` / `went` / `same`）
- **课纲**：S11 Top It Up（增加）、S8 Party at Beach（减少、还剩、倒着数）、S16 Piggy Bank——图画 + 故事这一步。
- **intro**：发生了什么？ **praise**：看得真明白！ **主持** chilli。
- **画面**：两张拍立得照片："之前"（左，竖屏在上）和"之后"（右，竖屏在下），拍的是同一个地方（小水池里的小鸭、长凳上的小鸡、盘子里的饼干、菜地里的小兔），中间一个箭头。下面 5 张"事件卡"：一扇小积木门 + 往里的箭头 + n 个点 = 来了 n；往外的箭头 + n 个点 = 走了 n；两张一样的小照片 = 没变。卡的画法在第一题由幽灵手和任务卡示范一遍。
- **手指**：点一张事件卡。
- **L1**：之前 1–4 只，变化 1–2（来 / 走用袋子），之后 ≤ 5；位置不变（新来的排在后面，走的从后面少掉），一眼能对。
- **L2**：之前 ≤ 6，变化 1–3；之后那张重新摆过（不能靠空位看）。
- **L3**：≤ 8；可能"没变"（摆法变了、个数没变；三种题型用袋子，"没变"约 1/5）。
- **L4**：之前那张看 2 秒就翻过去（背面朝上）："记住有几只！"；≤ 8。
- **L5**：之前那张只是一张数字卡（不带点），之后那张是图；≤ 10——从一个数接着数或倒着数。
- **作答**：5 张事件卡（方向 × 个数，加"没变"），对的位置用袋子；干扰：同方向 ±1、反方向同个数、没变。
- **答错讲解**：
  1. 蓝圈他选的卡："不是走了哦"（或"不是来了两只"）。
  2. 两张照片之间一对一连线；之后那张里多出来的一闪星光（来了），或之前那张里没配上的变成灰色虚线并带出门箭头（走了）："多了两只，是来了" / "少了两只，是走了"；同时接着数"三……四、五"或倒着数"五……四、三"。没变的题：全部配上："没有来也没有走"。
  3. 金圈对的卡："来了两只"。
- **就事论事**：不是走了哦 / 不是来了哦 / 不是来了两只 / 数量变了哦（他选"没变"时）。
- **场景**：`bluey_pool`（后院的小水池和草地，水里、地上都空）。道具现成：duck、chick、bunny、cookie、plate、carrot。
- **复习卡**：`sub10`；每题 `q.fact = factOf(来 ? '+' : '-', 之前, n)`（没变的题不记）。

#### B7「跟！」风筝线团 · `tangle5`

#### V5「送！」加号飞机、减号飞机 · `story5`（题型 `inc` / `join` / `dec` / `part` / `cmp`）
- **课纲**：S11 Top It Up（加法应用题两种意思：合起来、又来了）、S16 Piggy Bank（减法应用题两种意思：拿走一部分、减少）、S8 Party at Beach。

### 6.2 本世界里看起来相近的几对

- **P6 小剧场 和 V5 加号飞机**：P6 是"听到动词就动手做"（方向和个数），不出现符号；V5 是"认出一个故事要用哪种运算"，包括没有动作的合起来、求另一部分和比多少，不动手、不算数。
- **P7 钉板、J5 三角拼图、V7 积木转转**：P7 用线连点造形状；J5 用块填满一个轮廓；V7 转动固定的方块拼一个颜色图案。三种不同的"造"。
- **H5 剪纸对折 和 V6 切成一样的**：H5 判断哪条线是对称轴（翻折重合）；V6 自己切，很多切法切出的两块是转一下才一样（不是镜像）。两个游戏放在不同的岛（⑤、⑦）。
- **X5 从哪儿拍的 和 V8 穿过墙洞**：X5 找"相机在哪"，重点是前后左右的转换；V8 预测一座方块楼在一个方向上的轮廓。
- **A5 画路线、A6 看箭头走、B7 线团**：A5 是自己规划路线（有条件）；A6 是读别人的箭头；B7 只是眼睛跟线，没有选择。

### 6.4 如实说明：相近但保留的几处

同 W4 对 F8 迷宫的处理，下面几处和旧游戏属于同一类本领，玩法和判断不同，所以保留；委托方如果觉得太像，每一处都备了替换办法：

- **A6 看箭头走 ↔ D1 开车编程**：同一种方格地图，一个读、一个编。保留理由：学而思 S3 这一课就是"看方向走"，他测评里的路线题是弱项。替换办法：A6 改成"跟着一句一句的口令走"（只有语音，没有箭头卡）。
- **P5 捉迷藏 ↔ Q2 藏恐龙**：同属位置词。保留理由：前后（遮挡）和"反过来说"是他测评第 3 题的弱项，Q2 没有。替换办法：只留 L3–L5（以玩具为参照、找参照物、两个条件）。
- **B6 发生了什么 ↔ W4 I3 L5**：都有"来了几只"。保留理由：B6 的主要判断是方向（来了还是走了），正对他加减分不清的问题。
- **J7 拍下所有分法 ↔ N1 所有分法**：同一个知识点（N 的所有分法）。保留理由：学而思 S6 要"用实物分合"，J7 是实物和有序生成，N1 是在卡片里挑。替换办法：J7 改成"挪一个过去，两边各变成几"（一边多一个、一边少一个）。
- **J6 数图形填表 ↔ W4 I4 数图形**：都数图形。J6 不出组合图形。
- **X5 从哪儿拍的 ↔ W3 K4 从上面看**：都是视角。X5 不以"上面"为主，只把它当五个位置之一。

## 8. 进度与开启

### 8.1 新玩家

第二片海 7 个岛都插旗 → 灯会岛大结局播过 → 回到第二片海时门变金色、说"惊喜来啦！"（原来这里演的是去云上的门；现在改成去积木城）→ 点门："登上积木城啦！"、撒彩纸 → 积木城一个岛一个岛开（规则和第二、三、四世界一样：一个游戏 5 颗星开下一个，四个都过插旗，前面的岛都插旗才开下一个）→ 7 面旗都插上 → 积木城堡打开："积木城堡开啦！"、播"积木城大派对！" → 回到积木城时门变金色、"惊喜来啦！" → 点门飞到云上（"飞到云上去！"，第一次"飞到云上啦！"）。

### 8.2 孩子现在的存档

他在云上已经有旗子，`w3seen` 为真。更新后第一次进地图：

1. **积木城马上开**：`W5.open()` 为真（第二片海全过，或已经到过云上）。
2. **自动去一次**：地图第一次出现时（`MapView.specials`），满屏魔法光，飞到积木城："积木城开啦！"、撒彩纸，佩奇岛的云散开、发光，小手指着它。只演一次（记 `w5seen`、`gate5`）。积木城的门已经是金色的（`gate3` 本来就是真），点一下就回云上。家长也可以随时点门换地图。
3. **云上照旧**：给存档记 `w3pre = true`，云上的开放不再看积木城有没有过完。已经开的岛、打过 ✓ 的游戏、旗子、星星、圈数、复习卡都不动；云上下一个岛照旧在前一个岛插旗后打开。
4. **旗子计数**：积木城的 7 面旗和其他世界一起数（"二十面旗子啦！"……，数词表已经到四十）。

### 8.3 开放规则（给实现者）

```
LIVE5            : 已经上线的岛（build_w5.py 按 raw/js/w5/live.json 写进首屏）
W5.full          : LIVE5.length === 7
W5.open()        : W2.allDone() || Store.s.w5 || Store.s.w3seen
W5.allDone()     : ORDER5.every(w => W2.islandDone(w))
W5.check(show)   : 同 W4.check；只开 LIVE5 里的岛；全插旗时 fin5 = 'due'
W3.open()        : Store.s.w3 || Store.s.w3pre || (W5.full ? W5.allDone() : W2.allDone())
迁移（开机一次）  : if (Store.s.w3seen || Store.s.gate3 || (!W5.full && W2.allDone())) Store.s.w3pre = true
```

- 积木城还没做完（`W5.full` 为假）时，新玩家的云上照旧在第二片海之后开，不会被一个还没做完的世界挡住；那时开过云上的存档都记 `w3pre`，以后积木城做完也不会把云上锁回去。
- 家长"全部解锁"：加上 `ORDER5` 和 `Store.s.w5 = true`。
- 解锁和过关都是粘性的。

### 8.4 门环和没上线的岛

- **门环**：`nextSet()`：1 → 2；2 → 5（`W5.open() && gate5`，否则回 1）；5 → 3（`W3.open() && gate3`，否则回 1）；3 → 4（原样）；4 → 1。
- **第二片海的门**：`gate5` 的变金那一幕放在第二片海（条件：`W5.open() && !gate5 && fin2 === 'seen'`）。**去云上的那一幕搬到积木城**：条件 `W3.open() && !gate3 && (fin5 === 'seen' || !W5.full)`。
- **没上线的岛**：在地图上照样画出来，盖着云，点它云晃一下："新岛还在建哦！"，小手指向能玩的岛。`W5.check` 不开它。所以岛可以不按顺序做完，但只能按顺序开。

### 8.5 其他系统怎么接上

- **再玩一圈**（DESIGN §14）：`Laps` 按世界 id 记，对积木城直接生效；"每片海只在一个岛的旗边闪光"用 `MapView.ids()`，积木城是第五套；"回前面练一练！"指门时沿新门环走。要测：积木城的岛第一次进第 2 圈时的邀请、皇冠、火箭。

  - `shape`（图形：认、数）：一个小图里"几个三角形？"（5 张数卡，只数分开的图形）；
  - `op10`（用加还是用减）：两张故事卡，各点 + 或 −（一题两问）。

- **教一教**、**讲解设置（关 / 自动 / 一步一步）**：引擎通用，积木城的 `explain` 按 §4 分好步就自动生效；要测一步一步模式下"▶ 下一步"按钮不挡选项（P5 的玩具、B8 的格子、H8 的一屏东西最容易挡）。
