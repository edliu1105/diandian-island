# 点点岛 · 第四世界「星空」设计（PLAN-v2 A.2：10 以内加减）

## 总体

- **形式和第二、三世界一样**：7 个岛 × 4 个小游戏，第 4 个是推理测验；5 颗星开下一关，一个岛 4 关都过插旗，前面的岛都插旗才开下一个岛。
- **开启**：云上 7 个岛（含运算岛）都插旗、彩虹城堡的派对播过之后，云上中间的门变成金色，通往星空。
- **难度**：按教材顺序一个岛一个岛递进，每个游戏 L1–L5 各升一步。
- **新玩法**：28 种，和第一、二、三世界、运算岛的玩法都不重复，彼此也不重复。

| 岛（解锁顺序） | 起点 | 1 | 2 | 3 | 4（推理） |
|---|---|---|---|---|---|
| ① 佩奇·星球（零与符号） | 1 | F1 鳄鱼嘴：两边比大小，选 > < = | F2 选符号：3 ○ 2 = 5，选 + 还是 − | F3 拼算式：用给的数和符号卡拼出一个对的算式 | F4 符号代换：★=2、▲=3，★+▲=? |
| ② Bluey·星球（5 以内加） | 1 | I1 流星装罐：先落进 a 颗、盖上盖子，再落进 b 颗，罐里一共几颗 | I2 举手指：两只手举起的手指一共几根 | I3 两格漫画：前一格 2 只，后一格又来 1 只，现在几只 | I4 数图形：图里一共几个三角形 / 正方形 |
| ③ 睡衣小英雄·月球（5 以内减） | 1 | M1 算式找图：4 − 1 是哪幅图 | M2 飞船空座：5 个座位坐了 3 个，空几个 | M3 谁剩得多：两人各有几个气球、各飞走几个，谁剩的多 | M4 折纸打孔：对折打孔，打开后孔在哪 |
| ④ 汪汪队·火星（6–10 分合） | 2 | N1 所有分法：7 可以分成哪些，挑出所有对的（多选） | N2 凑数配对：哪两张卡合起来是 8 | N3 分合规律：8=1+7、2+6、3+5，下一行是什么 | N4 小数独：每行每列不重复，空格里是什么 |
| ⑤ 葫芦娃·星球（10 以内加） | 2 | O1 三个葫芦倒进碗：连加 a+b+c | O2 走哪条路：哪条路上的数加起来是 N | O3 数字金字塔：下面两块加起来是上面一块 | O4 数字规律：2、4、6、? |
| ⑥ 西游记·星宫（10 以内减） | 2 | F5 两次被吃：9 个桃，八戒吃 2、悟空吃 3，还剩几（连减） | F6 原来有几：吃了 3 个还剩 4 个，原来几个（求被减数） | F7 找钥匙：门上写 3，哪把钥匙（9−6、8−4、7−2）开门 | F8 迷宫：从哪个入口能走到出口 |
| ⑦ 复仇者·空间站（加减关系） | 3 | I5 想加算减：看 3+4=7，算 7−3 | I6 星际巴士：车上几人，上来几人、下去几人，现在几人（加减混合，车窗看不见里面） | I7 比多比少：A 有 5 个，B 比 A 多 2 个，B 有几个 | I8 猜数：比 3 大、比 6 小、不是 4，是几 |

## 每个游戏的规格（实现者照这个写，细节自定，但不得违反铁则）

### 共通约定

- **代码结构**：
  - 每个岛一个文件 `raw/js/w4/<f|i|m|n|o|x|v>.js`，规则写成 `W4R.F1 = { ... }`。
  - 注册在 `raw/js/w4/games.js` 里（背景、角色、图标、复习卡已经配好）。
  - 构建：`cp raw/index_pre_v2.html index.html && python raw/js/v2_patch.py && python raw/js/w4_core_patch.py && python raw/js/build_w4.py`。
- **参考写法**：云上的规则 `raw/js/w3a.js`–`w3d.js`（例如 `MSums`、`MBadges`），以及运算岛的 `MDoor`、`MCombine`、`MUnload`、`MFamily`（在 `raw/js/v2.js`）。可用的小件：
  - `W2X`（thing、cards、num、icon、hideAll）、`W3X`（card、tapCards、say、say2、decor2、ic）、`V2G`（dots、eq、numCard、op、frame）；
  - `K`（item、say、task、pop、hop、wiggle、ring、reg、L）、`place`、`numOptions`、`bagPick`、`CN`、`CNQ`、`UI.num`、`Count.beat`、`Sfx`、`T()`、`EASE`。
- **规则必须提供**：
  - 基本：`kind0`、`verb`（一个字 + ！）、`intro`（≤ 8 字）、`praise`（不能和答案相反的夸奖，可以为空数组）；
  - 出题与答案：`gen(G, o)` 返回 `{ k, answer, opts, ... }`，`k` 决定"同一题"；
  - 画面：`present(st)`、`place(st)`、`relayoutQ(st)`（横竖屏切换）；
  - 判题：`onGesture`、`next(st, strat)`（测试用：`'right'` 走对，`'wrong'` 走错）；
  - 揭晓与答错：`reveal(st)`、`feedback(st, ans)`（就事论事一句 ≤ 8 字）；
  - `decor(G)`。
- **记忆系统**：只问一个加减事实的题，`q.fact = factOf(op, a, b)`（10 以内）。
- **铁则**：
  - 星只给自己第一次就答对的题；每道题各算各的，答错的那道没有星，直接下一题（同类型同难度、换数），下一题答对就有星。
  - 不代做、不揭晓答案（答错不显示正确答案）；答错就事论事说一句、换新题；没有失败音，没有红叉。
  - 每句语音不超过 8 个汉字；两句的问题用 `W3X.say2`。
  - 点按目标不小于 88 CSS px，横屏 1180×820、竖屏 820×1180、1024×768 都在屏内、在最上层。
  - 一题只有一个对的答案（多选题 N1 除外：要选全对、不能多选）。
  - 背景不画要数的东西。
- **难度**：L1–L5 每一级都比上一级难一步（数更大、支架更少、步骤更多），L5 不能和 L4 一样。
- **验收**：`W4_ONLY=F1,F2 python tests/test_w4.py chromium 1`（生成、对、错、目标、真鼠标点按）。

### ① 佩奇·星球（零与符号，起点 1）

- **F1 鳄鱼嘴（比！）**
  - 题目：左右两边各一个数（或一堆点），中间空格，三张卡 `>`、`<`、`=`，问"哪个符号对？"。
  - 鳄鱼嘴朝大的一边张开，选项卡上画鳄鱼嘴的样子。
  - 难度：L1 两堆点（5 以内）；L2 点和数字；L3 只有数字（10 以内，含 0）；L4 一边是数、一边是 a+b；L5 两边都是算式。
- **F2 选符号（选！）**
  - 题目：`a ○ b = c`，选 `+` 或 `−`（L4 起 `○` 可在等号右边：`7 = 5 ○ 2`）。
  - 难度：L1 结果和点阵；L2 只有数字、5 以内；L3 10 以内；L4 等号在左边；L5 两个空要填（`a ○ b ○ c = d`，选项是两个符号的组合）。
  - 0 要常出现（`5 − 5 = 0`、`3 + 0 = 3`）。
- **F3 拼算式（拼！）**
  - 题目：给 3 个数卡和 2 个符号卡，孩子依次点卡片填进 `□ □ □ □ □` 五个空，拼成一个对的算式。点错位置的卡可以点回去，没有提交前不算错。
  - 判题：填满后自动判。
  - 难度：L1 只给 `+` 和 `=`；L3 起 `−`；L4 多一张干扰数卡；L5 两种拼法都对的只给一种（保证只有一个对的答案，或者任何真算式都算对，二者选一并在 `evaluate` 里写清）。
- **F4 符号代换（推理）**
  - 题目：上面两行"钥匙"，如 ★=2、▲=3，问 ★+▲=?、▲+▲=?、★+★+▲=?，三选一。
  - 难度：L1 一个符号；L3 两个符号；L5 从"★+★=4"推出 ★ 再算。

### ② Bluey·星球（5 以内加，起点 1）

- **I1 流星装罐（装！）**
  - 题目：a 颗流星落进罐子，罐子盖上变不透明（看不到里面），再落进 b 颗，问"罐里一共几颗？"。
  - 只能靠"记住 a 再接着数"。
  - 难度：L1 和 ≤ 3 且第一次能看；L2 ≤ 5；L3 盖上后才落 b；L4 ≤ 7；L5 落三次（a+b+c ≤ 9）。
- **I2 举手指（举！）**
  - 题目：两只手（SVG 画的手，不用角色图）分别举起 a、b 根手指，问"一共几根手指？"。
  - 难度：L1 ≤ 5；L3 起手只闪 2 秒再放下（要记）；L4 一只手是数字卡、一只是手；L5 和 ≤ 10，两只手都是数字。
- **I3 两格漫画（看！）**
  - 题目：左格"有 a 只"，右格"又来 b 只"（箭头和动画），问"现在有几只？"（L1–L3）。
  - L4 起选算式加结果（三张卡：a+b=c、a+b=c±1、a−b=…，错的都不成立）。
  - L5 右格是"又来了一些，现在 c 只"，问来了几只。
  - 东西用已有道具（例如 duck、chick、bunny、kitten）。
- **I4 数图形（推理）**
  - 题目：一个线条图，问"一共几个三角形？"或"几个正方形？"，三选一。
  - 难度：L1 分开的图形；L3 两个三角形拼成一个大三角形（共 3 个）；L5 田字格里数正方形（5 个）。

### ③ 睡衣小英雄·月球（5 以内减，起点 1）

- **M1 算式找图（找！）**
  - 题目：上面一个算式 `a − b`，三幅图（a 个东西划掉 b 个），问"哪幅图是它？"。
  - 错图：划掉的个数不对，或者总数不对。
  - 难度：L1 ≤ 3；L3 ≤ 5；L4 算式带结果 `a − b = c`，图里有一幅总数对、但剩下的不对；L5 选算式对应的"拿走"动作图。
- **M2 飞船空座（坐！）**
  - 题目：一排 n 个座位（2–5），坐了 m 个宇航员（道具 astronaut），问"还空几个座位？"。
  - 难度：L1 座位看得见；L3 座位上盖着（只说"一共 5 个座位"），看见坐了的；L4 n 到 7；L5 只告诉"5 个座位，空 2 个，坐了几个？"。
  - 这是"和 / 部分"的减法理解，和"拿走"不一样。
- **M3 谁剩得多（谁！）**
  - 题目：两个角色各有 a、b 个气球，各飞走 c、d 个（飞走的动画），问"谁剩的多？"，点角色。
  - 题目保证剩的不一样多。
  - 难度：L1 a=b；L3 不同；L4 气球数只用数字牌；L5 问"多几个"（三选一）。
- **M4 折纸打孔（推理）**
  - 题目：一张纸对折，在折好的纸上打 1–2 个孔（动画），问"打开以后是哪张？"，三选一。
  - 难度：L1 一个孔、左右对折；L3 上下对折；L5 对折两次、一个孔（打开后 4 个孔）。

### ④ 汪汪队·火星（6–10 分合，起点 2）

- **N1 所有分法（分！）**
  - 题目："7 可以分成？"，5–6 张卡（如 3 和 4、2 和 5、1 和 6、2 和 4、3 和 5），孩子点选所有对的再点"好了"。
  - 判题：选全对、没有多选才算对。
  - 难度：L1 6；L3 8；L5 10，而且有"4 和 3"这种顺序不同的同一分法（算对，要都选上）。
- **N2 凑数配对（配！）**
  - 题目：飞船上写着 N（6–10），下面 4–6 张数卡，点两张合起来是 N 的。
  - 难度：L1 4 张只有一对；L3 6 张；L5 卡片是点阵和数字混合。
  - 只有一对是对的，其余组合都不等于 N。
- **N3 分合规律（接！）**
  - 题目：竖着几行分合式 `8=1+7`、`2+6`、`3+5`，问下一行是什么，三选一（L1–L3）。
  - L4 中间缺一行；L5 倒着排（`7+1`、`6+2`）。
- **N4 小数独（推理）**
  - 题目：3×3 的格子，用 3 种图形（★●▲），每行每列不重复，一个空格，问"空格里是什么？"。
  - 难度：L3 起两个空格（问其中一个，高亮）；L5 4×4。

### ⑤ 葫芦娃·星球（10 以内加，起点 2）

- **O1 三个葫芦倒进碗（倒！）**
  - 题目：三个葫芦各装 a、b、c 颗种子，孩子依次点葫芦，种子倒进碗（碗不透明），问"碗里一共几颗？"。
  - 难度：L1 和 ≤ 5；L3 ≤ 8；L4 葫芦上只写数字；L5 选算式 `a+b+c=` 和结果。
- **O2 走哪条路（走！）**
  - 题目：2–3 条路，每条路上 2–3 个数字石头，问"哪条路上的数加起来是 N？"，点路。
  - 只有一条对。
  - 难度：L1 每条两个数、和 ≤ 6；L3 三个数；L5 和 ≤ 10，三条路。
- **O3 数字金字塔（垒！）**
  - 题目：下面两块的数加起来是上面那块。
  - 难度：L1 两块求上面；L3 三层求顶（只问顶）；L4 已知顶和一块，求另一块；L5 三层缺中间一块。
- **O4 数字规律（推理）**
  - 题目：一串数（或点卡）2、4、6、?；1、3、5、?；10、9、8、?；1、2、1、2、?，三选一。
  - L5 有 +2 / −2 / 重复三种混。

### ⑥ 西游记·星宫（10 以内减，起点 2）

- **F5 两次被吃（吃！）**
  - 题目：一盘 a 个桃（道具 peach），先是八戒吃掉 b 个（划掉、动画），再是悟空吃掉 c 个，问"还剩几个？"。
  - 难度：L1 一次（a ≤ 6）；L2 两次（a ≤ 6）；L3 a ≤ 9；L4 选算式 `a−b−c`；L5 只有数字。
  - 和 Z3 不同：孩子不动手，画面是静止的划掉。
- **F6 原来有几（猜！）**
  - 题目：一个篮子盖着，"吃了 b 个，还剩 c 个"（看见剩的 c 个），问"原来有几个？"。
  - 难度：L1 ≤ 5；L3 ≤ 8；L4 只有数字 `? − b = c`；L5 `? − b − c = d`。
- **F7 找钥匙（开！）**
  - 题目：门上一个数 n，三把钥匙上各写一个减法算式，只有一把等于 n，点那把钥匙开门。
  - 难度：L1 钥匙算式带点阵；L3 ≤ 10；L5 钥匙上是加减混合。
- **F8 迷宫（推理）**
  - 题目：一个方格迷宫，2–3 个入口（A B C 换成三种颜色的小旗），问"从哪个入口能走到出口（宝箱）？"。
  - 墙是线；只有一个入口通。
  - 难度：L1 4×4；L3 5×5；L5 6×6 而且路更绕。

### ⑦ 复仇者·空间站（加减关系，起点 3）

- **I5 想加算减（想！）**
  - 题目：上面亮着一个已知的加法算式 `a + b = c`，下面问 `c − a = ?`（L4 起 `c − b`），三选一。
  - L5 已知的是减法，问加法。
  - 重点是"用学过的算式想"，揭晓时把两个算式连起来。
- **I6 星际巴士（乘！）**
  - 题目：星际巴士（道具 spacebus，窗户是黑的，看不见里面）一开始车上 a 人（开头显示一次），到一站上来 b 人（宇航员走进车），下一站下去 c 人（走出），问"车上现在几人？"。
  - 难度：L1 一站；L3 两站；L5 三站。
  - 和 ≤ 10，始终不为负。
- **I7 比多比少（比！）**
  - 题目：上面一行"蜘蛛侠有 5 个"，下面"黑寡妇比他多 2 个 / 少 2 个"，问黑寡妇几个，三选一。
  - 难度：L1 有点阵；L3 只有数字；L5 反过来问"谁多 / 多几个"。
- **I8 猜数（推理）**
  - 题目：三条线索一条一条说（两句的问题用 say2），例如"比 3 大""比 6 小""不是 4"，数字卡 0–10 里点出那个数。
  - 线索用图标表示：大于号、小于号、划掉的数字；保证只有一个答案。
  - 难度：L1 两条线索；L5 三条加"是双数"。
