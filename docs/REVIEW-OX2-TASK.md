# 用户体验评审（点点岛 · 5 个选项 + 答错后看为什么 + 一局错 3 题不算星 · 第 2 轮，Fable 5.1 · high）

你是独立评审。对象是 `index.html`（点点岛）：给 4 岁中文孩子的 iPad 数学 PWA，四个世界、一百多个游戏。

**这是第 2 轮。** 第 1 轮（`docs/REVIEW-OX1.md`，9/10 APPROVE）评的是委托方 2026-10-10 的两项改动：每道选择题 5 个选项（只有 2–3 种答案的改成一题两问）、答错后给孩子看为什么。开发方的回应在 `docs/RESPONSE-OX1.md`。

第 1 轮之后又加了一条**新规则**（`docs/OPTIONS-EXPLAIN-SPEC.md` 规则三）：第 1 轮测出乱点的命中率约 1/5、乱点约 25 题还能集满一个游戏，委托方从三个方案里选了"一局里能猜的题错满 3 道，这一局的星不算"。实现是一个局末结算的账本（`Ledger`，`Session` 旁边），见 `docs/DESIGN.md` §5、`docs/DELIVERY.md` 1x。

请先读：
- `docs/OPTIONS-EXPLAIN-SPEC.md`（规则一到三，必读）；
- `docs/REVIEW-OX1.md`、`docs/RESPONSE-OX1.md`；
- `docs/DESIGN.md` §5（星星规则、账本）、`docs/DELIVERY.md` 1x。

代码（`raw/` 不在交付目录里，看构建结果即可）：`index.html`（引擎、`Session`、`Ledger`、第一、二世界）、`assets/js/w3games.js`、`w4games.js`、`v2games.js`（运算岛、复习题、宝石、钥匙局）。

## 铁则

- **星星**：只给孩子自己第一次就答对的题；答错的那道没有星，直接下一题；第二级提示之后答对不给星。**新**：一局里能猜的题（选择题、一题两问、多选，含复习题）错满 3 道，这一局的星、✓、开新游戏、宝石、复习箱升级、"学会"的证据都不算，局末星星变灰飘走，说"再来一局吧！"；错 0–2 道和以前完全一样；写、拼、搬、走、按数取物这类不能猜的题答错不算。
- **答错**：说一句就事论事的话，然后给他看为什么（蓝圈是他选的、金圈是对的），再出新题。没有失败音，没有红叉，不说"错"，讲解时不欢呼。
- **规格**：每句中文语音不超过 8 个字、都有录音；点按目标不小于 88 px；家长功能藏在长按齿轮里。

## 请重点检查

1. **第 1 轮的每一条**（P1–P6）是否真的改好、有没有带出新问题。报告里给每一条写结论（已修好 / 部分 / 没修好）。
2. **新规则（一局错 3 题不算星）**——这是这一轮的重点：
   - 乱点的孩子：真的乱点几个游戏（真实点按），集满一个游戏要多少题；和第 1 轮比；
   - 认真但会错的孩子：错 0、1、2 道的局星星和以前完全一样；错 3 道的局结算时是不是温和（没有失败音、没有红色、不在局中施压），孩子能不能理解"再来一局吧"；
   - 账本是否把该等到局末的东西都等到了局末（星、✓、开新游戏、插旗、宝石、复习箱、学会/过关的证据），错的记录照常；
   - 第 5 颗星：局还可能被作废时继续玩、局末才"集满啦"；不可能作废时立刻结束——孩子看起来自然吗；
   - 中途回家、切后台、iPad 杀掉 App：错不满 3 道的星不丢，满 3 道的不算；
   - "能猜 / 不能猜"的分类对不对（四个世界、复习题、钥匙局）；钥匙局作废时的表现；月考不受影响；
   - 家长面板"不算星的局"。
3. **回归**：5 个选项、讲解、一题两问、星星规则、进度和插旗、复习系统、首屏预算（`tests/test_boot.py`，现在 445 KB / 450 KB）、离线。
4. **画面**：横屏 1180×820、竖屏 820×1180、1024×768。

## 方法

- 用 `tests/harness.py` 和 Playwright 自己操作、截图。测试钩子：`window.__go(world, game, level, opt)`、`window.__q`、`window.__state()`、`gesture()`。
- 已有的测试：`tests/test_voidrule.py`（新规则）、`test_explain.py`、`time_explain.py`、`test_opt3.py`、`test_w4.py`、`test_rejections.py`、`test_stars`、`test_w2`、`test_w3`、`test_v2`、`test_v2r1`–`r3`、`spotcheck`、`test_boot`、`test_offline`；`tests/run_ox.sh` 一次跑完。可以跑，但要自己验证，不要只信测试。

  - 结束之前一定要写好报告，哪怕有实验没做完，也在报告里写明。
