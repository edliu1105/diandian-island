# 五个选项 + 答错后看为什么（委托方 2026-10-10，两个 App 所有世界）

## 委托方的原话要点

1. 孩子开始靠乱点过关。**每道选择题改成 5 个选项**：题型不变，只把错误选项加两个，让乱点过不了关。所有做过的世界、所有 App 都改。
2. **答错时给视觉上的解释和反馈**：
   - 告诉他为什么做错了：他选的那个为什么不对；
   - 哪个是对的、为什么对。
   
   例子：云上 Bluey 的"叠一叠"（两张九宫格透明卡叠成一张）。之前做过的和以后要做的，所有适合的题都按这个标准。
3. 字母和汉字的笔顺：英文按美国最权威的书写规范（Zaner-Bloser），中文按中国最权威的规范（《通用规范汉字笔顺规范》GF 0023-2020）。

## 规则一：5 个选项

- **范围**：凡是"从几个里选一个"的题（卡片、图、数、字、算式、路、旗、角色……），都给 5 个选项：1 个对的，4 个错的。
  - 原来 3 个就加 2 个；原来 4 个就加 1 个；
  - 原来已经 ≥ 5 个的不动；
  - 题型、玩法、难度递进都不变。
- **错误选项要像样**：看起来合理，但一定不对。
  - 数：答案附近的数，在本级的数范围内（例如 0–10），不重复。
  - 图 / 字 / 算式：同类的东西。
  - **永远只有一个对的答案**；生成器要自己检查。
  - 对的答案在 5 个位置里要均匀分布（用 bag，不要总在中间）。
- **答案本来只有 2–3 种可能的题**（> < =、+ 还是 −、左边还是右边、一样多还是不一样多、是 / 不是）加不出 5 个合理选项。这类题改成**一题两问**：
  - 同一道题里同时问两个这样的小题；两个都对才算这道题对、才有星（乱点的成功率从 1/2、1/3 降到 1/4、1/9）；
  - 只要有一个答错，就是一道错题。
  - 如果某个游戏用一题两问实在不合适，写明理由，并说明怎样另外防乱点。
- **不是选择题的**（写字、描数字、按数取物、亲手搬运、拼算式、走路等），本来就猜不出来，不用改。
- **布局**：5 个选项每个 ≥ 88 CSS px，在屏内、在最上层，横屏 1180×820、竖屏 820×1180、1024×768 都要成立。放不下就两行（3 + 2）。不能挡住顶栏（回家、主持人、星托盘）、题目条和角色。

## 规则二：答错后看为什么

**引擎的改动**：
- 答错以后，先说那句就事论事的话（`feedback`），然后进入 `st.phase = 'explain'`，`st.explaining = true`。
- 有 `explain(st, ans)` 就调用它；没有就调用这个游戏的 `reveal(st)`（答对时的揭晓动画）。
- 然后才出下一道新题。
- `cheerAll` 在 `st.explaining` 时什么也不做：答错后角色不欢呼。

点点岛在 `raw/index_pre_v2.html` 的 `Session.runQ`；字字岛在 `src/app.js` 的 `Session.runQ`，加法相同。

**每个游戏的 `explain(st, ans)` 应该做到**：
1. **他选的那个为什么不对**：用看得见的方式。
   - 数他选的那张卡上的东西："这是四个"；
   - 把不一样的那一格亮出来，用蓝色或灰色的圈，不用红叉；
   - 把他选的算式算一遍；
   - 让他选的那一块对上去，露出对不上的地方。
2. **对的那个是哪一个、为什么对**：
   - 金色圈出对的那个；
   - 演示为什么对，多数游戏可以复用 `reveal` 里的演示，但不欢呼、不说夸奖的话。
   - 叠一叠：两张卡真的叠起来，叠出的图和对的选项一格一格对上。
3. **时长**：整个解释约 2–5 秒，一点就跳过；不能把孩子晾在那里。
4. **语音**：每句不超过 8 个汉字，例如"看，这是四个""对的是这张""两张叠起来是这样"。新句子都要录音。

**铁则**：
- 这一条替换旧铁则"答错不揭晓答案"。那条是因为过去同一道题会再出一次，孩子可以挨个试过去；现在答错后出的是新题，所以给他看答案帮不了乱点。
- 其余照旧：答错的那道没有星；没有失败音，没有红叉，不说"错"；第二级提示之后答对不给星。

**哪些游戏要专门写 `explain`**：
- 推理题、看图题：叠一叠、俯视图、补图、找不同、矩阵、数图形、迷宫、数独、规律……
- 一切"为什么"不能从 `reveal` 看出来的题。

纯计数、计算题如果 `reveal` 已经把对的那个演示清楚了，可以只加第 1 步（他选的那个是几）。

## 验收

- 生成器：每道选择题 5 个选项（或写明的一题两问），只有一个对的答案，对的位置均匀。
- 每个游戏、每个级别答错一次：进入 `explain`，没有页面错误，出现对的选项的标记，然后出新题。
- 布局：5 个选项在三种尺寸都 ≥ 88 px、在屏内、在最上层。
- 原有测试照常通过：期望 3 个选项的地方改成 5 个。

## 规则三：一局错 3 题，这一局的星不算（委托方 2026-10-10 选定）

背景：两个 App 的第 1 轮评审都测到，5 个选项之后乱点的命中率约 1/5，乱点约 25 题还能集满一个游戏的 5 颗星（以前约 15 题）。委托方选了这条规则，两个 App 一样。

- **什么算错**：只算"能靠乱点猜的题"答错——选择题、一题两问、多选。写字、描红、按数取物、亲手搬运、拼算式、走路这类不能猜的题答错不算（乱点本来就做不对，不该连累认真做的孩子）。第二级提示之后答对：没有星，但也不算错。复习题、钥匙局里的选择题一样算。
- **一局里这样的错满 3 道**：
  - 这一局的星不入账：局中星星槽照常亮星（孩子看得到），**局末结算**时这一局亮起的星轻轻变灰、飘走，没有失败音、没有红色，主持人说"再来一局吧！"；
  - 这一局不能让游戏打 ✓、不能开新游戏、不能插旗；复习的宝石也不入账；
  - 这一局里答对的题也**不算进度**：不升复习箱、不算"学会"（字字岛"两局里自己认对"、点点岛的过关题）的证据；答错的照常记录（漏答补问、降箱）。
  - 错到第 3 道时不说任何话，局末才结算，不在局中给孩子压力。
- **错不满 3 道**：和现在完全一样，每道第一次就答对的题一颗星。
- **中途离开**（回家）：到那时错不满 3 道，已经答对的星照常算；满 3 道就不算。
- **家长面板**：每个游戏显示"不算星的局"有几局，家长能看出孩子是不是在乱点。
- 新句子（≤ 8 字、要录音）："再来一局吧！"。

验收：乱点模拟（每题随机点一个）集满一个游戏需要的题数大约是现在的 5 倍以上；每局错 0–2 道的孩子拿到的星和现在完全一样；错满 3 道的局：星不入账、不打 ✓、不开新游戏、不升箱、不算学会，没有失败音；中途离开的两种情况；不能猜的题答错不算。
