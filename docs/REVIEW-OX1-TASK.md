# 用户体验评审（点点岛 · 5 个选项 + 答错后看为什么 · 第 1 轮，Fable 5.1 · high）

你是独立评审。对象是 `index.html`（点点岛）：给 4 岁中文孩子的 iPad 数学 PWA，四个世界、一百多个游戏。

**这次评审的是委托方 2026-10-10 提的两项大改动**，覆盖所有世界：
1. 孩子开始靠乱点过关。**每道选择题改成 5 个选项**（加两个像样的错误选项）。只有 2–3 种答案的题改成"一题两问"。
2. **答错后给视觉上的解释**：他选的为什么不对，对的是哪个、为什么对。委托方的例子是云上 Bluey 岛的"叠一叠"：两张九宫格透明卡叠成一张。

请先读：
- `docs/OPTIONS-EXPLAIN-SPEC.md`：这次改动的规则（必读）；
- `docs/DELIVERY.md` 里关于这次改动的一节；
- `docs/DESIGN.md`、`docs/W4-DESIGN.md`：每个游戏的规格。

代码（`raw/` 不在交付目录里，看构建结果即可）：
- `index.html`：引擎（`Session.runQ` 里答错后的 `explain` 步骤）、第一、二世界的游戏、`numOptions`；
- `assets/js/w3games.js`：云上 28 个游戏；
- `assets/js/w4games.js`：星空 28 个游戏；
- `assets/js/v2games.js`：变形金刚运算岛、复习题。

## 铁则（这次改动后）

- **星星**：只给孩子自己第一次就答对的题。答错的那道没有星，直接下一题。第二级提示之后答对不给星。
- **答错**：说一句就事论事的话，然后**给他看为什么**（这次新加的，替换了原来的"答错不揭晓答案"，因为答错后出的是新题，看答案帮不了乱点），再出新题。没有失败音，没有红叉，不说"错"，讲解时不欢呼、不夸奖。
- **规格**：每句中文语音不超过 8 个字；点按目标不小于 88 px；家长功能藏在长按齿轮里。

## 请重点检查

1. **乱点还能不能过关**：每个世界挑游戏，用随机点按真玩几局，看拿星和插旗的难度。
   - 每道选择题是不是 5 个选项、只有一个对的、对的位置是否均匀；
   - 错误选项像不像样（不能一眼就排除）；
   - 一题两问是否清楚：孩子知道要答两个吗？两个都要对才算对；
   - 不是选择题的游戏，乱点过关的机会是否真的很小。
2. **答错后的讲解**：每个世界都抽查，尤其推理题、看图题（叠一叠、俯视图、补图、迷宫、数图形、数独、规律）。
   - 4 岁孩子看得懂吗：他选的那个为什么不对、对的是哪个、为什么对；
   - 时长 2–5 秒，点一下能跳过；
   - 没有红叉、没有"错"、不欢呼；
   - 讲解完出的是新题。
3. **画面**：横屏 1180×820、竖屏 820×1180、1024×768 都看。5 个选项每个 ≥ 88 px、不被挡、不出屏，不挡顶栏、题目条和角色。
4. **语音**：新句子 ≤ 8 个字、都有录音（`assets/voice/bank.json`）。
5. **回归**：星星规则、进度和插旗、复习系统、首屏预算（`tests/test_boot.py`）、离线都没退步。

## 方法

- 用 `tests/harness.py` 和 Playwright 自己操作、截图。
  - 测试钩子：`window.__go(world, game, level, opt)`、`window.__q`、`window.__state()`、`gesture()`。
  - 开所有岛：家长面板"全部解锁"，或直接改 `Store.s`。
- 已有的测试：`tests/test_opt12.py`（第一、二世界）、`test_opt3.py`（云上、运算岛、复习题）、`test_w4.py`（星空）、`test_w3`、`test_v2`、`test_v2r1`–`r3`、`test_stars`、`spotcheck`、`test_boot`、`test_offline`。可以跑，但要自己验证，不要只信测试。
- 截图和数据放 `tests/logs/`。不要改 app 的代码。
- **重要**：这是非交互模式，你的回合一结束会话就结束，后台任务不会再叫醒你。
  - 所有命令都在前台运行（长的命令分段跑，或加 timeout），不要放到后台；
  - 结束之前一定要写好报告，哪怕有实验没做完，也在报告里写明。

## 输出

写 `REVIEW-OX1.md`（中文），结构如下：

1. **总体结论**
2. **问题**：按严重程度排列，每条写证据和建议
3. **抽查了什么**
4. **分数**：单独一行 `SCORE: n/10`
5. **结论**：单独一行 `VERDICT: APPROVE`（9 分及以上）或 `VERDICT: REJECT`
