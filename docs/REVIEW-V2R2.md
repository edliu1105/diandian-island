## 1. 总体结论

第 1 轮的两个严重问题都真的修好了，而且不是只在测试模式下好：

- 复习题现在出在一块盖住舞台的素色板上。我在**正常游戏**（不是 `test` 模式）里让 10 种复习题型、算式卡三级支架和 20 以内变体各出一遍，横竖屏各一遍，真实鼠标点正确答案全部能交卷，最小点按目标 111 CSS px（方块）、卡片 148–265 px；本关的藤、楼层尺、命中层都在板下面。
- 过关题在正常游玩里会出现了：新存档按顺序玩，P2 第一局就问 P1 的「一眼看出几个」，B2 问 B1 的「比大小」，A2/A3/A4 依次问 A1/A2/A3 的卡，V2/V3 也一样；两次答对后不再问。

中等问题 M1–M7 和轻微问题 L1–L10、以及附录里的 C2/C10/C11/D2，我逐条用自己的实验或代码复核，都确认改了（见第 3 节）。一个新存档从第 0 天玩到第 20 天的模拟里，复习的节奏符合方案：每局 0–2 道，首次玩的局最多 1 道（加上漏答补问），每局至少 2 道本关题，钥匙每天最多 5 道、没有到期题直接给，刹车没有误触发，宝石、旗子、英雄按时出现。三片海 80 个游戏、星星、旗子、金门、彩虹城堡、描数字、首屏预算、离线的回归全部通过。

还不能批准的原因是一个新发现的内容错误，以及几处会影响孩子感受的中等问题：

1. **「哪个算式对？」这道复习题有两个对的算式。** 减法算式卡（`sub10`）的三张卡里**每一题**都有两个真算式（如图 3 个点划掉 1 个：`3 − 1 = 3`、`3 + 1 = 4`、`3 − 1 = 2`），加法算式卡（`add10`）四分之一的题也是（`5 + 3 = 9`、`5 + 3 = 8`、`5 − 3 = 2`）。孩子选了一个算得对的算式，会被说"再看一看"、不给星、卡降两箱、两题后再问一遍。这正是任务书点名要查的"一题两个对的答案"，而且和 Z4 自己"错的选项都是算不对的算式"的原则相反。它出现在运算岛的过关题里、所有加减卡到期的日子里，以及月测 15 题中的 4 题。
2. 闪现点数复习题的闪现和"老朋友来了！"同时开始，问题在盖住之后才问，没有再看一次的办法。
3. 一张卡一天之内可以连降两次（答错 −2，漏答补问再错又 −2），过关题还没到期答错一次就降 2 箱——叠加第 1 条，减法卡一局就能从第 5 箱掉到第 1 箱并给家长记一条"换个样子问两次都没对"。
4. Z1 和 Z2 大部分等级是同一道题；宝石册 36 颗大约一个月就用完，之后钥匙局照做但什么都不发生。

**结论：REJECT，7/10。** 第 1 条是生成器一处改动，第 2、3 条也不大；修掉之后这一期可以到 9。

## 2. 问题（按严重程度）

### 严重

**S1. 「哪个算式对？」（算式配图复习题，`RQ.eq`）常常有两个真算式**

- 证据：
  - `v2r2_exp1.log` `EQ-FOILS`：各生成 500 题，`sub10` 500/500 题有两个真算式，`add10` 127/500。
  - `rv_add10_P2_L.png`：图是 ●●●●● + ●●●，三张卡 `5 + 3 = 9`、`5 + 3 = 8`、`5 − 3 = 2`，后两张都成立。
  - 原因在 `assets/js/v2games.js` 的 `RQ.eq.gen`：干扰项 `f1 = [a, 反运算, b, '=', 正确结果]`——减法题的 `a + b = a+b` 永远为真，加法题当 a ≥ b 时 `a − b = a−b` 也为真。
  - 对照 `MFamily.gen`（Z4）：明确过滤掉了成立的算式（"a 4-year-old would rightly take it"），`v2r2_exp1.log` 里 Z4 500 题 0 个两真。
- 为什么是严重：
  - 语音问的是"哪个算式对？"，4 岁孩子按字面理解就是"哪个算得对"。他在 Z4 刚学会"算不对的是错的"，到了复习题却因为选了算得对的算式被说"再看一看"、不给星、卡降两箱（见 M3），两题后再问一遍，很可能再错一次。
  - 覆盖面大：`add10` / `sub10` 是运算岛四个游戏贴的卡（A2、V2 的加法也是），`add10` 还没过关时，运算岛内 Z3、Z4 会把它作为过关题来问，之后每个到期日（局内或钥匙）都会问；月测 15 题里 4 题是它，基线就不准。
- 建议：干扰项一律用**不成立**的算式（和 Z4 一样过滤），例如 `[a, op, b, '=', r±1]`、`[a±1, op, b, '=', r]`、换运算符但结果也错。语音可改成"哪个算式说的是它？"，但只改语音不够。补一条像 D-07 那样的门禁：`RQ.eq` 300 题恰好一个真算式。

### 中等

**M1. 闪现点数（`sub5`）复习题：闪现和"老朋友来了！"同时开始，问题在盖住后才问，没有再看一次**

- 证据（`v2r2_exp3.log` B，非快进）：复习板出现在 t=4548 ms，`Voice.say('老朋友来了！')` 在 4541 ms，`'刚才有几个点？'` 排在它后面（4542 ms 入队），卡片在 6073 ms 盖住——闪现 1.5 s 整个落在"老朋友来了！"这一句里。真机录音"老朋友来了！"约 1.2–1.5 s，孩子听到问题时点已经盖上了。
- 之后的提示梯子只是把问题再说一遍（`RevGame.gestureHint`），`st.covered` 一直是 true，没有任何重新闪现的办法。对照 v1 的 P1「溅！」：孩子自己让角色"跳一下"，泥点在自己的动作之后出现，再闪 0.9–1 s。
- 建议：先出盖着的卡片，说完"老朋友来了！"再由孩子点一下卡片（或等语音说完）才闪；第二级提示允许再闪一次（不揭晓、不扣星）。

**M2. 一张卡一天内连降两次；过关题没到期就答错也降 2 箱**

- 证据（`v2r2_exp3.log` C，`Mem.answer`）：第 5 箱、20 天后到期的卡，作为过关题答错 → 第 3 箱、明天到期；两题后漏答补问再错 → 第 1 箱。到期卡第 4 箱答错 → 第 2 箱，补问答对 → 仍第 2 箱（"当天补对不升"是对的）。
- 方案：§5 "答错降 2 箱"是对到期卡说的；§10 补问是"漏答队列"，不是第二次测；§12 过关题"两局里都没答对"才降到第 1 箱、记一条。现在一次过关题答错已经先降 2 箱，再在同一局里被补问时又降 2 箱。
- 后果：和 S1 叠加，`sub10` 一局内 5 → 1，家长面板出现"减法算式换个样子问两次都没对"。
- 建议：一天之内一张卡最多降一次（和升箱一样用 `up`/一个 `down` 日期把关）；过关题答错只记 `passFail`，不动箱，满两局再按 §12 处理。

**M3. Z1「等号门」和 Z2「机器人合体」大部分等级是同一道题**

- 证据：`Z_Z1_L2_q_L.png`–`Z_Z1_L5_q_L.png` 全是"● + ●●● = ?"选和（语音"合起来是几？"），`Z_Z2_L1_sum_L.png`、`Z_Z2_L2_sum_L.png` 是同样的两堆点 + "2 + 1 = ▢"选和（"一共几块？"）。两者只差装饰（门 / 两张卡）。Z1 的"两边一样多"只在门框和等号的颜色里，孩子从头到尾没有一个需要判断"相等"的动作：L1 是数 ≤ 5 个点（教 0 做得好），L2 起就是加法。
- 委托方要求"每个世界都要有新的玩法"，运算岛 4 个里实际是 3 种玩法 + 1 个重复；Z2 L3 起的"藏起来的部分"、Z3 的亲手搬、Z4 的一家才是新的。
- 建议：让 Z1 真正用等号——右边给一堆点或一张卡，问"两边一样多吗？"（是 / 不是），或让孩子选"哪张卡放进去两边才一样多"（右边是点阵而不是数字），到 L4–L5 再变成 `3 + 2 = ▢ + 1` 这样的等式。

**M4. 宝石册 36 颗约一个月用完，之后钥匙局照做、宝箱照闪，但什么都不发生**

- 证据（`v2r2_exp3.log` E）：`gems.n = 36` 时做完钥匙局：`Gems.turn` 直接返回，reveal 0 次，没有任何画面；第二天 `Gems.avail()` 仍为 true，宝箱继续脉动、地图继续说"找回老朋友！"。
- 算一算：每天 1 把钥匙 + 这片海 7 面旗 + 多出的复习星（打过勾的游戏每局 1 颗），模拟的孩子第 20 天已有 23 颗；真实孩子最晚 30 天左右到 36。方案写的是"一期 36 颗"，但前提是 W4 带着新的 36 颗按时上线；按方案第 28 条 W4 第 1 岛才要求在云上第 5 面旗之前到位。
- 建议：36 颗之后给一个兜底——册子翻到第二册（同样的 6 色重复、召唤的英雄轮换），或至少钥匙局结束时说一句"宝石册满啦！"并把宝箱的脉动停掉；W4 上线时再接上。

### 轻微

- **L1. 月测**：中途回家全部作废（`v2r2_exp3.log` D：答 3 题后回家 `tests.length = 0`），方案 §25 说"可以分两次做"；蓝图和方案不同：给我 N ×1（方案 ×2）、比大小 ×3（方案 ×2），"一半是新情境"没有——15 题全是日常复习题型换了素色底。写数、整点、推理属于二期可以理解，但 15 题的构成请在 DELIVERY 里如实写。
- **L2. 迁移前没有备份**：方案 §29 "先备份，再做版本化迁移，可以恢复"；代码里没有任何备份键（只有坏存档的 `ddi.corrupt`）。迁移本身只加字段、星旗不动（D-01、`test_stars` 旧存档用例都过），风险小，但方案写了。
- **L3. "会了"的判据**：`Mem.state` 只看箱位 ≥ 4（算式卡加"只看算式"级），没有 §21 的"两种表征各对过一次"。家长面板里的"会了"比方案宽。
- **L4. 钥匙局 / 月测里右上角的星托盘空着 5 格**（`key_q1_L.png`、`month_q1_L.png`）：这两种局永远不给星，孩子会等星星。建议藏掉托盘。
- **L5. 想看宝石册得先做钥匙局**：钥匙可用时点宝箱直接开局（`MapV2.ensure`），册子只能做完或退出后看；退出会计入"钥匙退出"信号，3 天 2 次就把钥匙缩到 3 题。建议宝箱先开册子，册子里再放"找回老朋友"的按钮（现在册子里已经有这个按钮）。
- **L6. 文档与实现的小出入**：`RESPONSE-V2R1` 说"继续"是英雄挥手，实际是绿色播放三角、擎天柱站在旁边（`stopgo_L.png`，4 岁孩子认得播放键，没问题，但文档写准）；早期信号里没有 §26 的"每面旗的用时"（`flagDays` 记了没有显示）；§16 的退出统计没有限定"前两周"。

### 判断而非缺陷

- 复习题的自动提示不算帮助（`softHint`）：它只是把问题再说一遍、让卡片亮一下，不做任何一步，所以第二级提示后答对照样给星。这和铁则"第二级提示之后答对不给星"的字面不同，但符合它的本意（提示没有帮孩子解题）；本关自己的题不受影响。我接受，建议写进 DESIGN §12。
- 复习题答错后，这一轮接着来的是本关自己的一道新题，答对也没有星（`[o* R:sub5! r o* R:sub5*]`）——v1 的"一轮一星、答错这轮的星就没了"规则；两题后补问答对可以拿星。合理，不改。
