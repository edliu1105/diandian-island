# 点点岛 · 第四世界「星空」用户体验评审（W4R1，独立评审 Fable 5.1）

评审对象：冻结快照 `review/W4R1`（`index.html` + `assets/js/w4games.js`，sw.js `v9b1f1d63`）。只读代码和文档，用 Playwright（Chromium）自己操作、截图、计时；没有改动 app 的任何代码。所有脚本、数据、截图在 `tests/logs/rv/`。

## 1. 总体结论

第四世界的 28 个游戏做得扎实：出题器经 56,000 道独立验算没有一道答案错、没有一道有两个对的答案；答错时的 252 次实测每次都只说一句就事论事的话、换同类型同难度的新题，没有失败音、没有红叉；星星规则在真实时长下成立（答错不给、下一题答对给、第二级提示后答对不给）；581 句语音全部 ≤ 8 个汉字且全部有录音；三种屏幕尺寸下 112 张截图画面干净、点按目标不出屏不被挡；开门、地图、锁、旗、星星城堡、派对、家长面板、复习混入都按设计工作；前三个世界、运算岛、复习系统、首屏预算（426.6 KB / 450 KB）、离线（4619 个资源）全部无退步。

但这一轮不能通过，主要因为一个孩子一定会遇到的缺陷：**星空每一面旗子插上时的那句庆祝语音是坏的**。旗子总数到第四世界已超过 20，而中文数词表 `CN` 只到二十，第 22–28 面旗说的是 `undefined面旗子啦！`——在 iPad 的录音模式下这句直接被静默跳过（没有录音），在设备引擎下会读出 "undefined"。这是新世界最重要的激励时刻，七个岛每个都会撞上。其次，O4 数字规律把数推到了 20（L2 起六成以上的题超过 10，L5 还有 1、2、4、7、? 这种步长递增的题），与"10 以内"这个世界的定位和 W4-DESIGN 的规格不符；另外有几个游戏的玩法逻辑与前几个世界重合度较高，按委托方"重复的关卡没有意义"的严格标准需要委托方裁定。

## 2. 问题（按严重程度）

### P1 · 星空插旗的庆祝语音是 `undefined面旗子啦！`（每个星球都会遇到）

- **现象**：云上全部插旗后 `Store.s.flags.length` 已是 21（6 + 7 + 8，含运算岛）。星空第一面旗是第 22 面。`MapView.plantFlag`（index.html:3018–3019）说 `CNQ(n) + '面旗子啦！'`，而 `CN` 只有 0–20（index.html:535），于是说出 `undefined面旗子啦！`。
- **证据**：`tests/logs/rv/review.json`：`flags_before: 21 → flags_after: 22`，`flag_said: ["undefined面旗子啦！", "能量宝石！", …]`，`CN_len: 21`；`map.json` 的 `said_flag`、`said_end` 同样出现两次。
- **孩子听到什么**：iPad 上开着录音库时，没有录音的句子"let go quietly"（index.html:1155）——插旗只有号角声，没有那句话；开发/无录音环境下由 TTS 读出 "undefined"。七个星球、七次都是如此。
- **建议**：`CN` 补到至少 30（或 n > 20 时改说"又插一面旗！"并录音），`lines()`/voice_bank 补录 二十一…二十八面旗子啦；补一条测试：插第 22 面旗时说的句子在录音库里。

### P2 · O4「数字规律」超出"10 以内"的范围，且难度与设计规格不符

- **设计**（W4-DESIGN ⑤ O4）："2、4、6、?；1、3、5、?；10、9、8、?；1、2、1、2、?"，L5 "+2 / −2 / 重复三种混"。
- **实现**（w4games.js O4）：L2 起起点可到 16–20，L3/L4 ±2 到 20，L5 是 ±3 或"步长每次加一"（1、2、4、7、?→11）。生成统计（`rv/uniq.json`，每级 400 题）：超过 10 的题占比 L2 60%、L3 78%、L4 80%、L5 99%；最大数 20。截图：`shots/land_O4_L5.png`（1、2、4、7、?，选项 11 9 10）、`shots/port_O4_L3.png`（14 12 10 8 ?）、`shots/ipad_O4_L2.png`（17 16 15 14 ?，选项 11 12 13）。
- **为什么要紧**：这是"葫芦娃·星球（10 以内加）"的推理关，孩子在这个世界刚学 10 以内加减，却要在 20 以内倒着数、按 3 跳、找步长递增的规律；1、2、4、7、? 对 4 岁孩子基本不可解，只能猜（三选一）。实现者注明"重复规律第二世界有了，所以不做"是合理的，但替代方案应该留在 10 以内（如 ±1、±2、从中间缺一个、从 10 倒数）。
- **建议**：全部级别把序列和选项限制在 0–10；L5 用"问号在中间/开头"+"±2"的组合提高难度，去掉步长递增。

### P3 · 几个玩法与前三个世界 / 本世界内部重合度高（需委托方裁定）

委托方的标准是每个世界玩法全新、彼此也不重复。对照 DESIGN §4/§10/§11/§12 的 84 种玩法，逐个比较后，以下几个是"换了皮、换了数的范围，核心判断方式相同"：

| 星空游戏 | 相近的已有玩法 | 重合点 |
|---|---|---|
| I3 两格漫画 **L4**（三张算式卡选对的） | 云上 R1 看图选算式（海豹来了/走了，哪个算式对） | 完全同一任务：看图选 a+b=c 的算式；只是 I3 的 L1–L3、L5 问"现在几只/来了几只"不同 |
| N4 图形小数独 | 第二片海 G4 矩阵推理（3×3 格子按行列规律，空格里是什么） | 画面几乎一样（3×3 图形格、一个问号、三选一）；逻辑从"规律"换成"不重复"，4 岁孩子看不出差别 |
| I8 猜数 | 第二片海 J2 线索推理（按颜色/天线/"不是…"逐条线索找机器人） | 同为"逐条线索排除"，只是线索从图片属性换成大小/双数 |
| F8 迷宫 | 云上 R4 水管（哪朵花能浇到水）、第二片海 D1 编程小路 | 同为"连通性判断：哪个入口通到终点" |
| I1 流星装罐 | 第一世界 A4 接着数（篮子盖着、篮牌 k、再来几只）、P3 收玩具（进箱看不见再问几个） | "盖住已有的 a，再落 b，问一共"正是 A4 的接着数范式；L5 三次落下又与本世界 O1（三个葫芦倒进不透明的碗）同构 |
| O2 走哪条路 ↔ F7 找钥匙（本世界内） | — | 都是"2–3 个算式里挑出等于 N 的那个"，一个用加法石头路、一个用减法钥匙 |
| M3 谁剩得多 | 第一世界 B1 谁的多 | 比多少前多了一步"各飞走几个" |
| I6 星际巴士 | 第一世界 A3 电梯（再来一只/走掉一只，现在几只） | 车上人数加减；I6 多站、多步 |

它们都不是逐字复制，教学内容也确实是新的（符号、连加连减、求被减数、加减关系），但按委托方"玩法不能跨世界复用、同一世界内也不重复"的字面要求，至少 I3-L4、N4、I8、I1-L5/O1、O2/F7 这五处应由委托方决定是否接受。DELIVERY 里"和前三个世界、运算岛的玩法都不重复，彼此也不重复"的表述偏乐观。

### P4 · 四个游戏在大部分级别只有两个选项，蒙对率 50%

- F2 选符号 L1–L4（+ / −）、M3 谁剩得多 L1–L4（点两个角色之一）、O2 走哪条路 L1–L4（两条路）、F8 迷宫 L1（两面旗）：共 13 个"游戏 × 级别"是二选一（`rv/uniq.json` 的 `nopt`）。
- 星只给首答对的题、5 颗星就开下一关，二选一的局平均 2.5 颗星靠蒙就能拿到，两局即可"过关"；DESIGN §1.4 防猜条款（位置袋、大小袋）对二选一不起作用。F1（> < = 三选一）、Z1 等号门（= / ≠ 二选一）已有先例，但本世界一下子多了四个。
- **建议**：F2 从 L2 起加第三张卡（例如 `=` 或 `×` 这种一看就不对的干扰、或"两个都不对"），M3 L3 起加"一样多"第三项（题目保证剩得不一样时就是干扰项），O2 L3 起三条路，F8 L1 也用三面旗。

### P5 · 故事型题目在高等级上孩子等得太久（真实时长）

`rv/timing.json`（Chromium，真实时长，从出题到能作答 / 从作答到下一题能作答）：I6 星际巴士 L5 **19.5 s / 22.9 s**，L3 12.9 s / 17.6 s；I1 流星装罐 L5 10.9 s / 16.4 s；F5 两次被吃 L3 7.2 s / 9.2 s；对照 F1 0.8 s / 3.5 s。I6 L5 一局 5 题约 3.5 分钟，八成时间在看车进站出站、乘客一个个走。I6 答错后重放整段故事（9.6 s）也偏长。建议：第二站起走路/开车动画加速 30–40%，乘客 ≥ 3 人时并排走；答错换题时略去"车上有 a 个人"之前的开场等待。

### P6 · L1→L2 的"难一步"在几个游戏里几乎没变化；O3 的 L3 比 L4 难

- M2 飞船空座 L1 座位 2–4 → L2 3–5；M3 气球 L1 两人都 3–4 个 → L2 都 4–5 个；N3 分合规律 L1 N=6–7 → L2 N=7–8（都带点阵）；I3 L1→L2 只是和从 ≤3 到 ≤5。规格上"每级难一步"成立但孩子感觉不到。
- O3 金字塔：L3 三层求顶（两次相加再相加）比 L4 两层求缺的一块（一次减法）更难，顺序反了；L5 三层缺中间一块且其下一块也空（要先算 a+b 再用顶减），对 4 岁偏难。
- 建议：M2/M3/N3 的 L2 换一种支架（例如去掉点阵或换问法），O3 把 L3 与 L4 对调。

### P7 · 小问题

- F3 拼算式：任何真算式都算对（好），但记进记忆系统的事实固定是出题时的 a+b=c（`q.fact`），孩子拼的若是 L4 用干扰数拼出的另一个真算式（如 3+1=4），进箱的事实不是他做的那个。
- I1 流星装罐的背景是夜空，天上画着小星星，而要数的恰是流星——与"背景不画要数的东西"的原则擦边（罐内外区分明显，影响小）。
- M2 飞船空座：舞台上空座是实心蓝椅子，任务卡里的"空座"图标却是白色虚线椅子，图标与画面不一致；"坐了"和"空着"只靠有没有宇航员区分。
- F2 L1–L4 答错时"加了会变多 / 减了会变少"虽是事实，但二选一下等于说出答案；配合 P4 一起改。
- 复仇者 I7 L5 的选项是"头像 + 数字"（谁多、多几），对 4 岁孩子需要靠语音"谁多，多几颗？"才明白，可考虑把"多"字图标放进卡片。
- `tests/harness.py` 的 `answer_question` 在真实时长下对 O1（先倒三个葫芦）会因 `max_steps=40` 用尽而不提交——是测试工具限制不是 app 问题（我用逐步驱动验证过 O1 在 0 ms 连点、60/300/1500 ms 间隔下都正常出卡、正常判对错；见 `rv/o1*.out`），但以后真实时长的测试会被它误导，建议按时间而不是步数计。

## 3. 抽查了什么

**自己的实验（脚本在 `tests/logs/rv/`）**：

## 4. 分数

内容质量和工程质量都高（出题正确、答错处理、星星铁则、语音、画面、回归全部过关），但有一个每个孩子都会遇到的庆祝语音缺陷、一个与世界定位不符的数字范围、以及需要委托方裁定的玩法重合。

SCORE: 8/10

## 5. 结论

VERDICT: REJECT

修好 P1（旗子数词）和 P2（O4 限制在 10 以内），并由委托方对 P3 的五处重合表态后，本评审认为可以进入下一轮；P4–P6 可以一并处理。
