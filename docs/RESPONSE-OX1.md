# 点点岛 · 对第 1 轮评审（OX1，9/10 APPROVE）的回应

评审建议交付前做的两件（P1、P4）和三条建议（P2、P3、P6）都做了；另外修了评审过程中发现的一个线上隐患。

- **P1 讲解句没有录音** → 改了。
  - 第一、二世界每个游戏、每一级、8 个种子各答错两题，钩住所有说出来的话（537 句），再把讲解代码里所有拼句子的模板按每个游戏自己的取值展开。补录 29 句：`这里不是零/十五…二十`、紫色 / 橙色 / 青色的几种说法、`在两个中间！`、Q2 的位置句、`方向不一样`、`再想一想`、D1 的两句。
  - `tests/test_explain.py` 的讲解部分现在检查每一句话都有录音（`Bank.has`），录音表没加载也算失败；这次 228 个游戏 × 级别、607 句全部有录音。
- **P2 两处讲解超过 6 秒、两处点一下跳过太慢** → 改了。
  - 叠一叠 L4：滑卡的同时圈出不一样的格子，6.6 s → 4.6 s。谁剩得多：两组同时演示，只说一句，6.4 s → 4.2 s。星空的测试另查出 I1 L5、I4 L4 稍长，也压到 4.8 s。
  - 跳过慢的原因是讲解句用了 `summary` 标签，点一下不会掐掉它。云上、运算岛、复习题、星空的讲解句都换成点一下就掐掉的标签，计数在跳过后不再一拍一拍地走。现在点一下 0.8–1.3 秒内结束。
  - `test_opt3.py` 新加 T 部分、`test_w4.py` 的计时部分：每个游戏真实速度讲解 ≤ 6 s、0.4 秒时点一下 2 秒内结束。
- **P3 谁剩得多讲解时选错的卡还亮着绿勾** → 改了：进入讲解时清掉两组的勾和黄底，只留蓝圈和金圈。同样的问题在 N1、N2、O2 也有，一并改了；`test_w4.py` 检查讲解结束时选错的那个身上没有选中标记。
- **P4 `test_opt3.py` 依赖交付目录里没有的文件** → 改了：文件不存在就当空表（所有句子都必须在录音表里）。
- **P6 一题两问的小圆点太小** → 当前这一问的圆点从 18 px 放大到 30 px，第二问开始时闪两下；"还有一个！"照旧。
- **P5 乱点仍能拿星，只是慢了** → 交给委托方决定。委托方选了"一局错 3 题就不算星"，两个 App 一起做，做完再送第 2 轮评审。
- **答错后的收尾语** → 字字岛的评审指出"再试一次！"暗示同一题会再来，点点岛也一样（`AGAIN`）。现在是"再来一题！""下一题来啦！""再来一个！"，都录了音。
- **线上隐患（评审过程中发现）**：Service Worker 的更新检查失败（iPad 断网、Wi-Fi 不稳）时，没有接住的 Promise 会被当成游戏出错，结束当前这道题。现在更新检查自己接住；全局的 `unhandledrejection` 只对游戏代码的错误结束题目，平台的错误（DOMException、音频 `play()` 被拒、网络 / Service Worker 的 TypeError）只记一笔。新测试 `tests/test_rejections.py`（27 项）。
