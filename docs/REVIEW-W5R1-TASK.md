# 用户体验评审（点点岛 · 新世界「积木城」· 第 1 轮，Fable 5.1 · high）

你是独立评审。对象是 `index.html`（点点岛）：给 4 岁中文孩子（在美国）的 iPad 数学 PWA。

**这次评审的是新世界「积木城」**（`docs/W5-DESIGN.md`，`docs/DESIGN.md` §15，`docs/DELIVERY.md` 1z）：放在第二片海和云上之间，7 个岛、28 个新游戏（P5–P8、B5–B8、J5–J8、A5–A8、H5–H8、X5–X8、V5–V8），外加 3 种新复习题（pos / shape / op10）。委托方睡前要求一口气做完，**已先上线**（提交 29374cb），这是上线后的评审。

**为什么做这个世界**：孩子（4 岁）进了云上，很多题跟不上——比如看到"5 只小狗走了 2 只"写 5−3，还不认识加减号。他刚做了学而思 PreK 4 的测评：数感、规律、推理多是 A+，弱项是空间（"三角形在兔子后面"的位置表达、走迷宫、用三角形拼火箭、数图形里的图形）。委托方给了学而思 PreK 秋季、春季的大纲（设计文档 §0–§1 有转录），要求按大纲做一个难度介于第二片海和云上之间的世界。核心：加减先用实物动作"来了 / 走了 / 合起来 / 拿走 / 还剩"做扎实再引入符号；全世界一套"走了的虚线 + 箭头、还在的实线"的画法；补空间。

## 委托方的要求与铁则

- 每个世界都要有新的玩法，不允许跨世界复用玩法；同一世界里也不重复（设计文档 §6 列了每个游戏最近的旧游戏和"相近但保留"的 6 处）。
- 内容按教材递进：岛一个比一个难，L1–L5 每级难一步；难度介于第二片海和云上之间。
- 星星只给自己第一次就答对的题；答错的那道没有星，直接下一题；第二级提示之后答对不给星。
- 每道选择题 5 个选项（只有 2–3 种答案的改一题两问）；答错后讲解（蓝圈他选的、金圈对的，2–5 秒，点一下跳过；家长可设关 / 自动 / 一步一步）。
- 不说"错"、没有红叉、没有失败音；每句语音 ≤ 8 字且有录音；点按目标 ≥ 88 px；家长功能在长按齿轮里；不用第三方库；委托方的角色原图不能重画。
- 已有的机制都要在新世界里工作：再玩一圈（皇冠、火箭）、英雄卡（现在 51 张）、复习卡、教一教、讲解设置。

## 请重点检查

1. **28 个游戏**：对 4 岁孩子清不清楚、好不好玩；L1–L5 是否每级难一步；有没有两个对的答案；乱点能不能过；讲解是否真的让他看懂"为什么"；一步一步模式每一步是否有意义。
2. **加减的意思**：P6 小剧场、B6 发生了什么、A7 对号入座、V5 加号飞机、op10 复习题——是否真能帮一个把"走了 2 只"写成 5−3 的孩子分清"走了几个"和"还剩几个"；符号引入的时机和方式。
3. **空间**：P5、B5、B7、J5、J6、A5、A6、A8、H5、X5、V6、V7、V8——是否补到了他测评里的弱项。
4. **不重复**：和第一到第四世界、运算岛的 112 个游戏比，玩法是否真的新（设计文档 §6）。
5. **难度定位**：是否比第二片海难一步、比云上容易（设计文档 §7）。
6. **进度与开启**：新玩家第二片海 → 积木城 → 云上；**已在云上的存档**（他的情况：19 面旗，云上进行到西游记·天宫）不能被锁、不能丢东西，第一次进地图飞到积木城一次；四片地图的门 1→2→5→3→4→1；积木城堡和大派对；地图、旗子、岛的画面。
7. **画面**：横屏 1180×820、竖屏 820×1180、1024×768；目标 ≥ 88 px、不被挡、不出屏、不挡顶栏 / 任务卡 / 角色；背景里没有要数的东西；44 张新图的质量。
8. **回归**：前四个世界、运算岛、复习系统、星星规则、首屏预算（`tests/test_boot.py`，447 KB / 450 KB）、离线。

## 方法

- 用 `tests/harness.py` 和 Playwright 自己操作、截图（钩子 `window.__go(world, game, level, opt)`、`window.__q`、`window.__state()`、`gesture()`；可直接改 `Store.s` 造存档）。
- 已有测试：`tests/test_w5.py`（`W5_ONLY=P5,...`、`W5_TIMING=1`）、`tests/w5_flow.py`（进度、旧存档）、`tests/shots_w5.py`、`test_w4`、`test_w3`、`test_w2`、`test_stars`、`test_v2*`、`test_opt3`、`test_boot`。可以跑，但要自己验证。已知：`test_offline` 的"complete release"一步在这台机器上是环境超时；`test_flow`/`test_hints`/`test_real_input`/`test_consistency` 是过时的旧测试。
- 截图和数据放 `tests/logs/`。不要改 app 的代码。
- **非交互模式**：所有命令前台运行（长的分段或加 timeout），结束前一定写好报告，实验没做完也写明。
