# 用户体验抽查评审 R5（Fable 5.1 · high）

评审对象：`index.html`（点点岛）。方式：按 `REVIEW_TASK.md` 抽查——只看孩子和家长看到、听到、摸到的东西，所有结论以我亲眼看过的截图和实际操作为准；代码只在定位原因时读了解锁/推荐/家长面板三处。截图在 `shots/r5/`（本轮自写脚本）和 `shots/spot/`（`spotcheck.py` 种子 20260926）。

## 总体结论

画面、角色、答错后的引导和节奏都已是成熟儿童应用的水准：目标大、点得中、答错不打叉、带着数一遍再出同类新题，24 关抽到的画面没有一处数字看不清或被挡。但“过关/解锁”这条新规则只改了一半：地图上的“下一步去哪”（发光小手）和家长面板仍按旧的掌握门判断，导致岛已经插旗、新岛已经开了，小手还一直指着佩奇，家长面板也说不出这个岛为什么算过关。再加一处竖屏角色被硬切的裁切 bug，离“顶级付费应用”还差一小步。

## 发现的问题（按严重程度）

**[中等] 1 推荐小手永远停在佩奇岛，不随新过关规则前进**
证据：`shots/r5/L_map_two_passed_oldsave.png`（佩奇、Bluey 都插了旗、葫芦娃已开，小手仍在佩奇）；`L_unlock_after.png`（刚玩完 B4 触发解锁、葫芦娃云散开后，仍指佩奇）；`L_map_all_passed.png`（六岛全部插旗、灯会岛亮起，仍指佩奇）；`L_map_peppa_passed_tap_locked.png`（佩奇已插旗时点未开放岛，“先去这里玩吧”+小手仍指佩奇）。每种状态下 `MapView.recommend()` 都返回 `peppa`。
原因：`recommend()`（`index.html:2522`）取第一个 `!cleared` 的开放岛，`cleared` 是旧掌握门；新规则的 `passed()` 没有用上。不识字的孩子在地图上唯一的“去哪”线索就是这只小手，过关后它指错方向；家长看到旗子和小手矛盾也会困惑。
→ 建议：推荐顺序改为第一个 `unlocked && !passed(id)` 的岛，都过关时指最新开放的岛或灯会岛；解锁云散开后小手应立刻移到新岛上。

**[中等] 2 家长面板不认新过关规则：已插旗的岛显示“开放”，通过条件只列旧掌握门**
证据：`shots/r5/L_parent_after_passed.png`——佩奇（4 关各玩一遍）和 Bluey（10 星）在地图上都插了旗、葫芦娃已开放，面板里两者都写“开放”而非“已过关”，“通过条件”一栏是“P1·近7题对0，缺题型 …”，没有任何一行告诉家长“4 个小游戏各玩过 ✓ / 10 星 ✓”。家长看不出下一岛为什么开了、离过关还差什么。
原因：`index.html:2790` 只看 `ws.cleared`。
→ 建议：状态列改为“未开放 / 开放 / 已过关（4 关玩过 或 10 星） / 已掌握”；通过条件第一行加“已玩过：P1 ✓ P2 ✓ P3 · P4 · ｜ 星 3/10”，掌握门保留在下面。

**[中等] 3 P4「插！」竖屏：乔治被一条直线硬切掉下半身，切口下露出背景橱柜**
证据：`shots/r5/P_P4_L2_ready.png`、`P_P4_L2_reveal.png`，放大图 `crop_P4_table.png`。乔治（左）在桌面上方约 10–15 px 处被水平直线截断，截线下面是绿色橱柜而不是桌子，看起来像贴纸被剪坏；佩奇（右）也是直线截断，只是恰好贴着桌沿不明显。横屏未见此问题。
→ 建议：桌后角色用桌面形状（椭圆）做遮挡，或把裁切线下移到桌沿以下并随视口比例计算。

**[轻微] 4 大结局合影：美国队长被钢铁侠和雷神的锤子挡住，只剩头盔一角**
证据：`shots/r5/L_finale_b.png`，放大图 `crop_finale_captain.png`。39 人合影里唯一一位几乎看不见脸的主角，而他正是复仇者岛的主持人。
→ 建议：把队长排到前排空位（如浩克右侧）或让锤子举向另一侧。

**[轻微] 5 B1「比！」竖屏复测题：草莓在盘子里随机散布，有的压在盘沿上**
证据：`shots/r5/P_B1_L2_3guide.png`——左盘 4 颗草莓两颗贴着盘边、位置零散；与首题（`P_B1_L2_2wrong.png`，整齐一排）风格不一致，对“一个对一个”比较也不友好。
→ 建议：复测题沿用一排排列，只换数量和材料。

**[轻微] 6 老存档六岛全过关时，启动不会自动播大结局**
证据：造存档六岛 `played` 全满 → 重载 → 地图 `finaleDue=true` 但停在地图（`shots/r5/L_map_all_passed.png`），要点灯会岛才播（`L_finale_a.png`）。正常游玩路径（最后一岛在一节结束时过关）会自动播，所以只影响老存档；灯会岛本身亮起、可点，不算卡住。
→ 建议：启动检查里 `finaleDue && !finaleSeen` 时进地图后延迟播放一次。

**没有发现的问题（说明验证过）**：解锁链不会卡住——佩奇 4 关各一题 + Bluey 4 关各一题后，下一节结束时葫芦娃开启并有“新小岛开啦”云散开；老存档 23+12 星启动即开葫芦娃、汪汪队仍锁；六岛过关后灯会岛亮起、大结局可播可重看。齿轮长按 1.6 s 有金色进度环反馈（`L_gear_midpress.png`）并直接进入家长面板；轻点不进入，只弹“家长你好：请按住小齿轮”。所有抽到的关卡可点目标最小边都 ≥ 56 px，没有屏外目标；答错流程（P1、H2、X3、B1、A2）都是“指出差在哪 → 带着数 → 换一道同类题”，无失败音、无打叉；WebKit 与 Chromium 零页面/控制台错误；`spotcheck.py` 56/56、`test_unlock_easy.py` 4/4。
